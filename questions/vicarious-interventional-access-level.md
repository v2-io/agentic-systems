# When agent B watches agent A act, is what B learns Level 1 or Level 2? If A's action was unconfounded with the outcome's causes it acts like an intervention for B; if A acted because of what A knew, it is associational. Canon's Mode 2 (#der-loop-interventional-access:115) covers an observer intervening on a sub-agent, not an observer learning from another agent's own interventions. Composites and communication (#hyp-communication-gain, #hyp-solicitable-escape) rest on which it is. Source: #def-pearl-causal-hierarchy Working Notes gold 'Belongs elsewhere' (Gemini 829314).
