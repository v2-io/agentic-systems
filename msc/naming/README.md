# msc/naming/ — orientation note

This tree is the naming-cycle archive: brainstorms, per-architecture
vote files, aggregates, alias clusters, and the name-transition records.
It is a low-churn historical workspace and is **deliberately not
swept** for the 2026-05-15 rename.

## Naming: read "AAD" here as "AAT" — *except the name-decision records*

The mathematical core was renamed **Adaptation and Actuation Dynamics
(AAD) → Adaptation and Actuation Theory (AAT)** on **2026-05-15** (the
prior 2026-04-16 rename was ACT → AAD). In the vote/aggregate/brainstorm
files here, the framework-label "AAD" is incidental — read it as
**"AAT"** (the segment slugs those files voted on are unchanged).

**The name-decision records are different and intentionally keep
"AAD" literal:**

- [`name-transition-aad.md`](name-transition-aad.md) — records the
  *ACT → AAD* decision and its rejected-candidate analysis.
- [`collision-check-brief.md`](collision-check-brief.md) — the collision
  research that *produced* AAD as the answer.

Sweeping those would make them falsely read "ACT → AAT", an event that
never happened. Their "AAD" is the *object the document is about*, not a
stale label. Leave them exactly as-is.
