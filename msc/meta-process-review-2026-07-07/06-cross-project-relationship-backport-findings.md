## 0. Headline

The neighborhood is **one body with a working outward circulation and a stalled return circulation.** ASF concepts flow *out* into instruments and papers healthily and habitually. Results flow *back* poorly: the largest single instance — the NeurIPS back-integration workstream — was scoped 2026-05-08 and, per the CHANGELOG's own words (2026-05-12), its Phase A/B/C absorption **"hasn't yet run"**; only opportunistic cross-references have landed since. **Backport debt is the neighborhood's central metabolic failure, and it is a direct instance of the review's target bottleneck** (bandwidth + routing, not idea-supply).

Only **two of four relationship-types carry backport debt** (downstream instruments; derived publications). Typing the relationship correctly is most of the leverage. The **vivarium `ASF.md` ⇄ `doc/vivarium.md` bridge is the only fully-realized collaboration SOP in the neighborhood** and is the template the others lack.

## 2. (a) De-facto processes actually running

1. **Outward concept-flow (healthy, habitual).** ASF results are extracted into instruments/papers continuously. Evidence: 8 submitted papers all cite AAT/AAD as anonymized formal ground (ops `papers/submitted/`); vivarium and vestigia both explicitly build on named canon segments; git shows the outward direction is routine (`137f8aa doc: vivarium enters as the authored-world calibration laboratory`, the whole synthese/neurips/AIES paper trail).
2. **Opportunistic backport (running, but incidental-only).** When an agent auditing a canon segment happens to notice a sibling repo carries a sharper form, the fix lands. Witnessed twice: causal-access transportability (`#der-loop-interventional-access` gained the (C1)-(C3) gating from NeurIPS Paper 2 Lemma 5.3, CHANGELOG 156) and AAD-5 Fisher-gain (cross-ref to Paper 3 chart-rescaling no-go, CHANGELOG 681). **This is discovery-by-accident, not a swept process.**
3. **Bridge-authoring on reframe (running for vivarium only).** When Joseph reframes a project as ASF-related, a session authors the two-sided bridge. Done once, fully, for vivarium (2026-07-04→07-06, 3 dated `ASF.md` sessions). Not repeated for vestigia/practica/causal-language.
4. **Spike-as-findings-conduit (running).** A visiting session in a sibling repo deposits an ASF spike that "releases recommendations to the standing cycle" read-only on canon (the TST-derivation spike; `doc/sop/spikes.sop.md §0c`). This is the de-facto instrument→ASF channel — **but it terminates at "released to the cycle," and the cycle is the bottleneck.**

## 4. (c) Emergent patterns from git history

1. **Repo fission at paper-time.** `causal-language` was born by forking `embeddings`'s methodology (first commit `b768227` 2026-05-13) and later *renamed* from `intrinsically-causal-language`. The neighborhood grows by spinning empirical legs off canon spikes, each becoming a repo. Pattern: spike → dedicated repo → paper → (intended) backport. The chain **reliably completes through "paper" and reliably stalls at "backport."**
2. **Two-sided bridges are a July-2026 invention.** `vivarium/ASF.md` and `doc/vivarium.md` both date 2026-07-04+. Before that, cross-project relationships lived *only* in ASF project-memory `project_*.md` files (one-directional, and now 37-53 days stale). The bridge-file pattern is new, good, and not yet propagated.
3. **Backport lands when a paper restructures a taxonomy, not when it sharpens a lemma.** The one fully-completed backport (three-deaths → `#def-death-as-factor-loss`, CHANGELOG 79) happened because the paper forced a *structural* rethink Joseph was already engaged in. The lemma-level sharpenings (NeurIPS) — higher in number, lower in salience — are the ones that rot. Emergent lesson: **structural debt gets paid; precision debt accretes.**
4. **Upstream substrate repos go quiescent, not dead.** firmatum (2 commits, last Mar 2026), `_core/*` (no git, Dec 2025) look abandoned by recency but are *canonical sources still actively cited* by 2026-07 work (TST spike cites `_core/tst/vault`; PROPRIUM-v2 is the live operational ontology). Recency is a **false abandonment signal** for UP-type repos.

## 7. (f) Candidate meta-process definitions

Raw material for the MECE hierarchy. Format: **name** — trigger — steps — current health.

- **P-06.1 Backport-debt reconciliation (sibling → canon).** *Trigger:* a sibling repo (paper/instrument) develops a result sharper or more-correct than its canon counterpart. *Steps:* scan paper↔segment correspondence → for each gap, apply strengthen-before-soften + integration-is-replacement → land the sharpened form in the segment (not a pointer) → mark the plan-doc progress. *Health:* **BROKEN as a swept process; RUNS opportunistically.** The NeurIPS instance has been stalled 2 months; the three-deaths instance completed because it was structural. This is the highest-leverage process to formalize.
- **P-06.2 Cross-project bridge authoring.** *Trigger:* Joseph reframes a project as ASF-related, or a project starts citing canon. *Steps:* author the two-sided bridge (`<proj>/ASF.md` + `agentic-systems/doc/<proj>.md`) with a one-paragraph fit, a conceptual mapping, ASF-familiarity gates, and a findings-flow discipline; register a terminology-collision check. *Health:* **DE-FACTO but instantiated once (vivarium).** Excellent template; not propagated to vestigia/practica/causal-language which carry live debt.
- **P-06.3 Instrument findings-flow-upstream.** *Trigger:* a downstream instrument (vivarium/vestigia/embeddings/causal-language) produces a measured or empirical result that instantiates or stresses AAT. *Steps:* deposit an ASF spike read-only on canon → release recommendations to the standing cycle at honest tier → cycle authors segments → spike becomes reasoning-trail archaeology. *Health:* **EMERGENT — channel exists (TST spike proves it), terminates at "released to the cycle"; the cycle is the bottleneck.** Steps 3-4 don't reliably fire.
- **P-06.4 Upstream-substrate citation discipline.** *Trigger:* canon (03/04) needs an operational-ontology primitive (PROPRIUM term, ELI-infrastructure fact). *Steps:* cite the canonical `_core`/firmatum source (PROPRIUM-ONTOLOGY-v2 for concepts, ennaos State.md for ANIMA split, `_core/tst/vault` for original TST) → never treat recency as abandonment → surface stale mappings (`def-proprium-mapping` still draft). *Health:* **STABLE but under-instrumented** — the canonical-source pins live in a 53-day-old memory file, not in a checked discipline.
- **P-06.5 Terminology-collision ledger (cross-project).** *Trigger:* two projects touch the same object, or a project coins a term. *Steps:* the coining project defers to ASF's term, records the carve in its LEXICON, runs an ASF collision-check before settling. *Health:* **ASPIRATIONAL beyond vivarium↔ASF** — the vivarium ledger exists; no collision check has run for embeddings/causal-language/practica vocabulary against canon.
- **P-06.6 Relationship-memory currency.** *Trigger:* a project's relationship to ASF changes (new reframe, rename, stall). *Steps:* update the `project_*.md` memory + repoint dead paths. *Health:* **STALE** — all relationship memories are 37-53 days old, miss the July reframes, and one (`intrinsically-causal-language`) carries a dead path.
