# Meta-Process Review — 2026-07-07 (working artifact)

Convened by Joseph: a full-company-style review of the meta-processes that *are* running (and that *should* be running) in agentic-systems and its project neighborhood — the **first deliverable** before any reconciliation/cleanup sweep. The point is to make the enormous, mostly-can't-be-held-in-one-head project legible, and to loosen the real bottleneck: not ideas (there's a surplus) but Joseph's bandwidth and a decision-routing failure where he's the blocker on calls he often can't reconstruct from an agent's scrollback.

## Method

**Phase 1 — Discovery fan-out (10 peer agents, one per cluster).** Each orients on the whole first (orientation letter + reflection #28 +, where the slice touches theory/ELI/culture, the primary papers and the causal-language honest-null), writes a short reflection, explores, then maps its cluster through the lenses:
- **de facto** — what actually happens
- **aspirational** — what the tracking files / SOPs say should happen
- **emergent** — patterns visible in the git commit history (a rich, habitually-overlooked primary source)
- **stale / broken / abandoned** — concrete decay
- **blocked on Joseph** — decisions genuinely his
- **candidate meta-process definitions** — raw material for the MECE map

Out-of-scope-but-important surfacings are captured and passed back, not discarded. Each agent writes `NN-<slug>-findings.md` + `NN-<slug>-reflection.md` here.

**Phase 2 — Synthesis.** Draft → adversarial critique → finalize a MECE meta-process hierarchy (de-facto / aspirational / emergent per process), plus a decision-routing mechanism design (the leverage-on-leverage piece).
