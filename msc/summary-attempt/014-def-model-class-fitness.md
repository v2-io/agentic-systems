# Model Class Fitness (definition — axiomatic)

A second measurable quantity is defined: **model class fitness**, the supremum of sufficiency over an entire model class. Where sufficiency measures how well a *specific* model retains the chronica's predictive information, class fitness measures the *ceiling* — the best any model in the agent's representational class can achieve. The two quantities formalize a distinction the framework will soon make load-bearing.

The structural-inadequacy condition states the framework's central use of this quantity: when class fitness falls below $1 - \varepsilon$, no model in the class achieves sufficiency above that threshold. The gap is *structural*. It cannot be closed by better parameter estimation, more data, or longer training within the current class. This is the trigger condition for the structural-adaptation-necessity result that arrives in Chapter 4 — when class fitness is too low, the agent must change *what kind of model* it is, not merely tune its parameters.

The distinction parallels bias vs variance in statistical learning: class fitness is about bias (what the class can in principle represent); instance sufficiency reflects both bias and estimation quality. A low instance sufficiency might mean the agent needs more learning; a low class fitness means the agent needs a different *kind* of model entirely. An important operational point: the agent cannot directly compute its class fitness (that would require searching over all models in the class). What it can observe is the *signature* — persistent mismatch despite adequate learning (high gain, sufficient data, converged parameters). When the floor doesn't go down with more work, the floor is structural.
