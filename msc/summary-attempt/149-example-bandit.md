# Nonstationary Bandit (RL Domain) (appendix worked example — conditional)

A second worked example mapping AAT's machinery onto a classical reinforcement-learning setting: the *nonstationary bandit problem*. The framework is honest upfront that **the mapping here is approximate** — AAT's concepts *organize* RL phenomena, but the quantitative relationships are *structural analogies*, not derivations. Where the mapping is exact versus approximate is marked explicitly throughout.

The mapping. The bandit arms map to actions; the reward distributions map to environment state; arm-reward correlations map to model components. The agent's model maintains uncertainty about each arm's expected reward; the mismatch signal is the per-pull reward residual; the optimal gain principle approximately holds for the per-arm update (with the approximation degrading away from conjugate-Bayesian gain forms). The adaptive tempo measures the rate at which the agent acquires useful arm-value information; the persistence condition becomes a *regret-management condition* — the agent's tempo must exceed the rate at which the reward distributions drift.

The framework's *approximate-mapping admissions*: typical RL methods (epsilon-greedy, Upper Confidence Bound, Thompson sampling) do not exactly implement the optimal-gain principle; their gains are *related to* the uncertainty-ratio gain but not identical. The framework treats them as *operationally approximating* the optimal gain principle, with the approximation quality depending on the method. UCB approximates the gain via confidence-bound-as-uncertainty; Thompson sampling approximates via posterior-as-uncertainty. The framework's prediction is that *both should converge in steady state toward the optimal-gain behavior* — which empirically holds.

The worked example covers the *nonstationary case* (drifting reward distributions) where the framework's machinery is *most distinctive* from classical RL. The forgetting prerequisite from the strategy-persistence schema becomes operational: under nonstationarity, *the agent's effective sample size on each arm must be bounded* by an explicit forgetting mechanism, or the agent's gain converges to zero and the agent stops tracking. The detection-latency floor predicts how long the agent takes to recognize a regime change in arm values — *expected cycles scales linearly with accumulated experience*. The matrix-Loewner persistence formulation predicts that an *adversary choosing which arm to perturb* can target the agent's *weakest direction* (highest experience, slowest detection) — the empirical pattern that adversarial bandit attacks concentrate on long-trusted arms.

The framework's overall posture: this is the framework's *bridge to RL theory*. The framework does not claim to subsume RL theory; it claims that RL methods are *operational approximations of AAT primitives* under regime-specific scope conditions, and that AAT's machinery predicts RL phenomena that classical regret analysis does not (the forgetting-as-prerequisite finding; the detection-latency floor; the adversarial-targeting concentration on accumulated-experience).
