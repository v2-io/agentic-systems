# Shared Intent (definition + discussion — discussion-grade)

The framework applies its information-bottleneck framing to *inter-agent communication*. When sub-agents within a composite must coordinate, they face a communication problem: transmitting the full purposeful state (objective plus strategy) is expensive (high bandwidth, high latency), but acting without any shared purpose wastes coordination potential. The **shared intent** is the IB-optimal compression of the sender's purposeful state — transmit enough to align behavior, not more.

The construction is an information-bottleneck objective with the *jointly optimal action* as the relevance variable: minimize the mutual information between the sender's full purposeful state and the shared message, subject to preserving sufficient information for the recipient to compute the coordinated action. At high trade-off weight, the agent communicates more detail (approaching full model sharing); at low trade-off weight, communication is minimal (approaching independent action). The shared intent is the *minimal sufficient statistic* of the sender's purposeful state for predicting jointly optimal coordination behavior.

The IB compression *preferentially preserves* three things, in order: **terminal objectives** (what the agent is trying to achieve — compact, change slowly), then **high-level strategy** (which approach, not which specific steps — moderate size, moderate change rate), and last **strategic details** (specific edge credences in the strategy DAG — large, change fast, low coordination value).

This gives the framework a clean reading of an empirical organizational pattern: **commander's intent** in military doctrine. The commander communicates *what* to achieve and *why*, not *how*. This is IB-optimal if objectives change slowly and strategies change fast — communicating objectives gives a long shelf life per bit transmitted. The framework predicts this pattern *structurally*, from the information-bottleneck trade-off, not as a managerial convention.

For agents with bounded communication capacity (bandwidth-limited channels, finite context windows), the strategy DAG must be summarized for transmission. A 500-node strategy DAG cannot be shared in full; the IB compression identifies which structural features of the DAG matter for coordination. The framework also notes that the same compression is useful for an agent preserving its own state across context boundaries (the language-model 100% context turnover problem) — store the compressed version of the purposeful state, not the full state.

The framework is honest that the formulation makes several strong assumptions: the sender must know the jointly optimal action (which requires knowing other agents' states); the compression is lossless in the IB sense (real communication introduces noise, delay, and misinterpretation); the trade-off parameter is fixed rather than dynamically adjusted. The qualitative prediction (communicate purpose before plans before models) is more robust than the specific IB formulation.
