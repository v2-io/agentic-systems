# Causal Information Yield (definition — exact)

The framework defines a scalar quantity attached to each available action: the **causal information yield** (CIY), measuring the *action-distinguishability* of an action — how different its interventional outcome distribution is from what alternative actions would produce. The construction uses Pearl's intervention operator $do(\cdot)$ and is the expected KL divergence between the outcome distribution under intervention $do(a)$ and the outcome distribution under intervention $do(a')$, averaged over a reference distribution of alternative actions. CIY is non-negative by construction; it is zero for passive observers or agents whose actions don't affect outcome distributions; it is strictly positive exactly when actions causally alter what is observed — the property that distinguishes Pearl-Level-2 (interventional) from Level-1 (associational) epistemic access.

A subtle conceptual point is made central. CIY measures *distinguishability*, not *learning value*. An action can have high CIY even when the agent already knows the outcome distributions perfectly: the distributions *are* different (high CIY), but the agent learns nothing new by confirming what it already knows. High CIY is therefore *necessary* for learning (indistinguishable actions can't teach anything) but not *sufficient* (distinguishable actions only teach when the agent is uncertain). The two quantities approximately coincide when model uncertainty is high (the agent doesn't know the distributions yet, so distinguishable actions also have high expected information gain) and diverge when uncertainty is low. A heuristic $\lambda$-weighting that later appears in the framework's unified exploitation-exploration objective partially compensates by suppressing the CIY term when model uncertainty is low — making the exploration term behave more like expected information gain. The compensation is honest about being heuristic; a proper expected-information-gain formulation that would replace CIY in some domains is named as an open direction.

A qualitatively distinct class of action receives attention: **query actions** — accessing the model of another agent. When a reliable source exists (an expert, a database, a well-trained language model), a single well-formed question can yield information equivalent to thousands of probe-observe cycles. The reason is precisely that the source's model has already performed the compression work, and the response transfers the *output* of compression rather than requiring the receiver to reconstruct it. The update from a query depends on trust in the source, not on observation channel noise; the response arrives already compressed in the source's representational framework (introducing a translation cost when frameworks don't align); and encountering another agent's model can trigger *structural* model change rather than merely parametric update — incorporating external representational structure rather than building it de novo ("grafting").

The adversarial dual of query actions is named: **deceptive responses**. The same channel that enables cooperative knowledge transfer can be exploited to degrade the receiver's model. A deceptive response yields positive CIY in the strict information-theoretic sense, but the content drives the mismatch *upward*. Successful deception exploits high trust to inject a large, misdirected update. In the Lyapunov machinery that arrives later in Part I, this is the formal handle for adversarial disturbance through the observation channel.
