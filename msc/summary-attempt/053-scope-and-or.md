# AND/OR Combination Scope (scope — robust-qualitative)

The strategy DAG's parameterization is committed: causal combination at nodes is *approximately conjunctive* (AND — all parents required) or *disjunctive* (OR — any parent sufficient), without strong interaction effects between parents. Each node is assigned a combination type by answering the causal question: "if I remove one parent, can this node still be achieved?" Yes → OR. No → AND. With single-parameter edges (one number per edge rather than a $2^k$ conditional probability table), this gives $k$ parameters per node instead of an exponential explosion.

The scope is honest about being a *restriction*, not a derivation. It converged independently across three different formalism attempts. The excluded case — *complementarity, substitutability, and interaction effects between parents* (synergistic drug interactions where combined effect exceeds the sum; complementary goods where neither is useful alone; strategic surprise where action combinations matter more than individual actions) — requires richer combination rules and is named as a legitimate divergence point for future work.

The framework documents *why* this restriction rather than alternatives. **Noisy-OR universally** — the first formalism attempt — was rejected because it *systematically overestimates conjunctive structures*. The framework gives a concrete illustration: three required key results at 95%, 90%, and 99% should multiply to about 85% (the AND combination) but noisy-OR computes them at over 99.99% — the noisy-OR model literally cannot represent "all of these are required." This was the primary motivation for the AND/OR revision. **Weighted combination** (introduced in a second attempt) was rejected because it reintroduces a two-parameter estimation problem per edge and the same k-of-n threshold semantics can be represented within AND/OR by nested structure (group alternatives into OR-nodes, then AND the groups) — keeping estimation localized rather than spreading it across new per-edge parameters.

The deeper *parsimony argument* is that for binary-outcome nodes, AND and OR form a complete Boolean basis — any Boolean combination can be decomposed into layers of AND/OR (disjunctive/conjunctive normal form). Under bounded cognition (the information-bottleneck constraint on representational capacity), the agent needs the most expressive low-parameter representation, and AND/OR is the natural candidate. The framework is explicit that this is *parsimony-motivated* rather than derived necessity, and that for continuous or multi-valued outcomes the same completeness properties don't necessarily hold — natural analogs would be min/max or additive/multiplicative combination, but their completeness is an open question.
