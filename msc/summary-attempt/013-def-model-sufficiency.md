# Model Sufficiency (definition — axiomatic)

A measurable quantity is defined: **model sufficiency**, the fraction of the chronica's predictive information about future observations that the compressed model retains. The construction is information-theoretic — a ratio formed from conditional mutual information that takes the value 1 when the model is a sufficient statistic for prediction (knowing the full history beyond the model adds nothing), 0 when the model retains no predictive information at all, and intermediate values for partial sufficiency.

Two scope considerations are surfaced. First, sufficiency is well-defined only when the chronica carries non-zero predictive information about the future beyond what the action sequence alone supplies. In saturated-noise environments or prediction-vacuous regimes (fully iid observations independent of history), the denominator vanishes and sufficiency is undefined — predictive sufficiency is a property *of a prediction task*, and there must be a task to be sufficient for. Downstream constructs that build on sufficiency (model-class fitness and the structural-adaptation-necessity result) inherit this scope.

Several conceptual distinctions are drawn that the framework will rely on later. Sufficiency is *relative to the prediction task*: a model sufficient for one horizon may be insufficient for another. Sufficiency is *not the same as accuracy* — a model can be sufficient (capturing all predictive information in the chronica) while being wrong in absolute terms if the chronica itself is systematically biased; sufficiency measures completeness of compression, mismatch measures accuracy. Sufficiency is *predictive, not causal* — it measures Level 1 (associational) information; it does not by itself guarantee the model supports Level 2 (interventional) queries; that requires an additional condition (backdoor sufficiency relative to actions) addressed when value objects are defined later. Sufficiency is *policy-relative* — different policies generate different future action sequences, which changes which observations are relevant; a model sufficient under a conservative policy may be insufficient under an aggressive one that visits states the model cannot predict. And sufficiency is *trajectory-relative* — measured against *this agent's* chronica, not against a model-state equivalence class; two copies of the same $M_t$ exposed to different event streams each have their own sufficiency.
