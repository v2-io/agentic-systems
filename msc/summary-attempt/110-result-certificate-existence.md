# Certificate Existence (appendix result — exact, linearized level)

The framework's central anchoring identity. **A stability certificate exists for an agent exactly when the agent is exponentially stable about its target**. The organizing slogan — *an adaptive system is an operator whose contraction rate exceeds its target's drift rate* — is *not a heuristic* but this equivalence, with the *certificate as witness*.

A **stability certificate** is a symmetric positive-definite metric $\mathcal{M}$ for which the one-point sector condition holds in the $\mathcal{M}$-inner-product on a ball around the equilibrium. At the linearized level, the existence of such a certificate is *equivalent* to the system matrix being Hurwitz (exponentially stable) by the classical Lyapunov theorem. **The certificate is not unique**: it is whatever positive-definite metric makes the dynamics contract.

The framework names a striking unification: the certificate *specializes* in different sub-cases of the framework to four different familiar metrics. For **Bayesian agents** it specializes to the *Fisher information metric*. For **Kalman agents** it specializes to the inverse-prior-covariance. For **gradient agents** it specializes to the *loss Hessian*. For **linear-Hurwitz or PID agents** it specializes to a *plant-selected Lyapunov metric*. These are *not four separate stories* — they are *one object under four certificates*. The framework's posture is that the unification is structural: the same Lyapunov equivalence underlies all four cases, with the specialization determined by the agent class.

The framework treats this segment as the **spine** of three meta-patterns it has been developing: the *equilibrium stability certificate* anchors the three-meta-segment picture, with separability, additive coordinate forcing, and identifiability-floor instances all describable as *facets* of certificate-existence — *scope-of-existence* (separability), *forced-coordinate* (additive-coordinate-forcing), *boundary* (identifiability-floor). Three failure modes are provably distinct (Helmholtz / Sylvester / Mori-Zwanzig); the *plurality is the content*. The certificate-existence equivalence is what the rest of the framework's meta-architecture organizes around.
