# Composite Agent (scope — robust-qualitative)

The scope condition that distinguishes a *composite agent* from a *multi-agent system*. A set of purposeful sub-agents constitutes a *composite agent* only when their objectives exhibit sufficient teleological alignment to define a coherent composite purpose. Without this condition, the sub-agents form a multi-agent system that may still be analyzed — but the *composition machinery* (closure defect, team persistence, composite tempo) does not apply because there is no composite agent whose quantities to compute. This parallels the single-agent agency scope: before asking how an agent adapts, one must check that an agent is *present*.

The scope condition is satisfied via *any* of **four disjunctive routes**. **(C-i) Shared composite objective**: all sub-agents' policies are approximately optimal under a common objective — the strongest alignment. **(C-ii) Hierarchical derivation**: sub-objectives are derived by structure-preserving decomposition from a parent objective (military chain of command; corporate department structure) — sub-agents may not individually know the parent. **(C-iii) Mutual-benefit alignment**: a relevance variable exists such that joint actions raise each sub-agent's expected value above the non-cooperation baseline (symbiotic coexistence, commensal ecologies, trading partners) — the weakest route that still qualifies. **(C-iv) Equilibrium-convergent strategic interaction**: an equilibrium concept (Nash, correlated, coarse correlated) exists such that coupled best-response dynamics converge to its support — qualitatively distinct from the first three: requires *neither* shared objectives *nor* hierarchical derivation *nor* mutual benefit, only *structural convergence* of the strategic interaction. Composites satisfying (C-iv) are **strategic composites**; their macro-state is defined relative to the equilibrium structure rather than to a shared target state.

The routes are *not* shown to reduce to a common scalar threshold. Each carries its own operationalization. A composite may satisfy multiple routes simultaneously; only one is required for scope. Routes (C-i) through (C-iii) are progressively weaker requirements for what teleological alignment means; (C-iv) is structurally distinct and admits *adversarial* composites with partially-opposing objectives.

The framework distinguishes carefully what the scope captures. Cyclic games (rock-paper-scissors, matching pennies) lack a pure-strategy Nash but admit mixed Nash and coarse-correlated-equilibrium convergence, so they satisfy (C-iv). The narrow category that *fails* (C-iv) entirely is games with no equilibrium concept whose support is reachable by any admissible dynamic — a small class. The asymmetric attacker/target case (one agent treated as exogenous parameter rather than as a sub-agent running its full loop) is a multi-agent phenomenon, not a composite — handled by adversarial-destabilization machinery rather than by composition machinery.

The framework is explicit about why this is a *scope condition* rather than just a quality metric. Without the scope condition, a "composite" with no defining objective is a *fiction* — closure defect can still be computed as a projection property, but calling the result a composite agent strains the term. Making this a scope condition resolves the category issue: composition applies *where the composite objective is well-defined*.

A specific load-bearing role: the framework's third identifiability-floor instance (composite contraction certification from component-marginal data is structurally impossible) has *four structural escapes*, but each escape needs a coherent target to certify. **Scope-satisfaction via at least one of the four routes is the enabling condition** for any of the escapes: without it, the "composite" is ill-defined and the escapes have no coherent target.
