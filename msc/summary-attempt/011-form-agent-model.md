# The Reality Model (formulation — robust-qualitative)

The agent's internal representation of how the world works is committed to a specific form: $M_t = \phi(\mathcal{C}_t)$ — the model is a many-to-one compression of the chronica into a model space $\mathcal{M}$. This is presented honestly as a formulation choice rather than a derived result. Alternatives exist (history-based policies that map chronica directly to actions without an explicit model state), but the formalism here commits to analyzing agents as carrying a state object that mediates between history and future action.

The compression is many-to-one *by design*: multiple distinct histories may produce the same model state. This is not a deficiency but the essential function of the model — retaining what matters and discarding what does not. The framework is deliberately agnostic about *how* an agent realizes $M_t$: a Kalman filter holds a state estimate plus covariance matrix; a reinforcement-learning agent holds a value function; a developer holds a mental model of a codebase; a language-model agent holds its context window contents plus retrieved memory. The formalism asks only that $M_t$ exist as a well-defined object that the agent's policy can condition on.

The load-bearing commitment hidden in the notation is the **completeness assumption**: by writing $M_t = \phi(\mathcal{C}_t)$, the framework assumes $M_t$ captures *everything* the agent retains from its history. Anything not in $M_t$ is, by construction, lost to the agent. This makes $M_t$ the complete epistemic substate rather than merely one component of a richer internal representation. Whether $M_t$ retains *enough* information for adaptive work is a separate question, taken up in the model-sufficiency segment.

Degenerate cases sit at the edge: a PID controller's $M_t$ retains only the error signal and its integral/derivative history, with no predictive capability beyond extrapolating recent trends. The formalism accommodates this by allowing $\mathcal{M}$ to range from trivial (scalar) to rich (full world model). The PID's impoverished model places it in the "blind seeker" region of an agent spectrum to be made formal later.
