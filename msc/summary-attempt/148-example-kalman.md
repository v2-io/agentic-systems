# Kalman Filter End-to-End (appendix worked example — exact)

A complete instantiation of AAT's machinery on a classical Kalman filter — the framework's *cleanest exactly-derivable case*. Every AAT primitive maps to a familiar Kalman quantity: the scope condition holds; the agent's model is a Gaussian state estimate plus covariance; mismatch is the innovation (observation minus predicted observation); the optimal gain is the Kalman gain (the uncertainty ratio formula coincides with the Kalman gain in the linear-Gaussian case); the update is the standard Kalman update; the sector condition holds globally with sector parameter equal to the Kalman gain; the persistence condition reduces to the classical observability and detectability conditions.

The framework treats this as the **canonical instance** of the framework's structural correctness. Every AAT result that holds for Kalman filters is *exactly* the standard control-theoretic result for Kalman filters under the same scope. The framework's contribution in this instance is not adding new results to Kalman theory; it is *embedding Kalman in a more general framework that handles the same primitives across non-linear, non-Gaussian, and non-fully-observable agent classes* — with the Kalman case as the special case where everything reduces to closed-form.

The worked example covers: the framework's recursive update reduces to the Kalman state-update equation; adaptive tempo equals event rate times Kalman gain; persistence is exactly observability plus detectability; the mismatch decomposition recovers the standard innovation-decomposition into model error and observation noise; the persistence-information-rate floor recovers Mitter-Newton's optimal-information-rate bound that Kalman-Bucy saturates.

The framework's posture: **this is the framework's calibration on a problem with known exact answers**. Where AAT predicts what Kalman theory says, the framework is *minimally correct*; where AAT predicts beyond Kalman scope (non-linear, non-Gaussian, partial-observability, multi-agent), the framework's reach is *outside* Kalman scope. The Kalman instance is the *anchor point* that grounds the framework's abstract machinery in a familiar concrete case.
