# Strategic Calibration (definition — discussion-grade)

A fine-grained companion to the chapter's control-regret diagnostic, locating where in the strategy DAG miscalibration lives. The **edge residual** for each edge is the difference between the predicted value increment from completing the parent step (as predicted by the strategy) and the observed value change attributable to that step. The **strategic calibration residual** is an $L^2$ aggregation over active edges with importance weighting (e.g., criticality on the plan's critical path). Where the control regret says *how much* value is being left on the table, the strategic calibration residual says *which edges* are miscalibrated.

The framework is honest about several conditions and limitations. The edge residual is meaningful only when the edge was actually traversed, the model is adequate (so observed value changes are signal rather than noise), and the agent followed the strategy's prescription (otherwise the residual conflates a bad plan with bad execution). Without the execution-fidelity condition, a positive residual could mean either "the plan is wrong" or "the agent didn't follow the plan" — and those require different remedies. The status is discussion-grade because the specific $L^2$ aggregation and the importance weighting are sensible first passes but not derived; the conditioning requirements make the quantity hard to estimate in practice.

The framework also draws a careful distinction between *two* strategic mismatch quantities. The **strategy-plan-confidence error** is the scalar gap between the agent's computed plan-confidence score and the independence-model plan value at true edge parameters — computable from status propagation alone, without credit assignment, and the sector condition transfers to it (this is the persistence target for which formal results exist). The **strategic calibration residual** (this segment) provides finer-grained per-edge diagnostics but requires credit assignment to compute, and its persistence properties remain open. The two are related (both measure strategy-reality mismatch) but not interchangeable.

A subtler **credit-assignment problem** is named. The edge residual subtracts the predicted value increment from the observed value change — different *types* of quantity. The prediction comes from the strategy's internal causal model; the observation comes from empirical measurement. The subtraction is meaningful only when the observed value change can be *attributed to the specific edge*. For edges with a single parent, attribution is straightforward. For multi-parent AND/OR nodes, the observed value change at the child reflects the combined effect of all parent edges, and decomposing it into per-edge contributions requires additional structure (Shapley-value decomposition, sequential observation of parent completions). Absent clean attribution, the residual measures "how well did the overall prediction work?" rather than "how well did this specific edge predict?" — still useful for aggregate calibration, but not sufficient for targeted edge revision.

This is also identified as a **second-order inference** — it requires accumulating evidence over multiple edge traversals, making it inherently slower to evaluate than the epistemic mismatch (which updates on every observation) or the satisfaction gap (which can be evaluated from the model and strategy alone).
