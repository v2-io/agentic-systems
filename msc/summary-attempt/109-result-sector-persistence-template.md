# Sector-Persistence Template (appendix result — exact)

The abstract Lyapunov persistence argument *stated once parameter-free*, so that the framework's many persistence-flavored results can be cited as *instances* without re-proving the argument. Any state variable evolving under bounded-correction dynamics with bounded disturbance admits the same persistence conclusion under three preconditions: **(T1) zero correction at zero state** (no correction when the state is at target); **(T2) local sector condition** (the correction function points inward with at least baseline efficiency in a radius-$R$ region); **(T3) bounded disturbance** (deterministic bound or stochastic with bounded variance).

Under these preconditions, the template gives the same conclusion as the chapter's central inequality: the state is ultimately bounded by *disturbance rate / sector parameter* (Model D, $1/\alpha$ scaling) or *root of variance times root of dimension over sector parameter* (Model S, $1/\sqrt{\alpha}$ scaling). The two scalings produce the framework's distinction between Model D and Model S regimes that propagates through every result that cites the template.

**The template's value is taxonomic economy**. AAT's persistence-flavored results across the entire framework — epistemic persistence (Part I), strategic persistence (Part II), team persistence (Part III), composite-closure (Part III), composite-tempo, adversarial-destabilization, identity-continuity across context turnover (later volumes) — are all *instances of the same template*. Each instantiation specifies only what varies: its state variable, correction function, effective disturbance rate, and reserve. **The Lyapunov boilerplate is absorbed once**; each downstream result's distinctive content is just the *effective-disturbance decomposition* particular to its setting.

The framework counts at least seven instantiations: epistemic mismatch + environmental disturbance (chapter's central inequality); strategy-plan-confidence error + strategic disturbance (the strategy-persistence schema); per-edge credence error + experience-rate disturbance (the edge dynamics); team-persistence with signed-coupling effective disturbance (cooperative as negative, adversarial as positive); composite closure with closure-defect-driven disturbance; adversarial destabilization (persistence-condition negation); and the closed-form critical-mass result (the bridge lemma's strong-monotonicity assumption upgraded to derived). Each is the template applied with a different state variable and effective disturbance, *not* a separate Lyapunov argument.

The framework names the template as one of the *cleanest demonstrations of internal economy* in AAT: many results, one Lyapunov skeleton, with the distinctive content sitting in the *effective-disturbance decomposition* per case. The mathematical home is monotone-operator theory (Rockafellar 1970; Bauschke-Combettes 2017); the sector condition is a *one-point strong monotonicity condition*, with the composition bridge-lemma's stronger condition corresponding to two-point monotonicity. AAT's relationship to the broader theory is specialization rather than generalization, but acknowledging this is what makes the template feel *earned* rather than parochial.
