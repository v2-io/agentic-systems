# Multi-Agent Scope (scope — axiomatic)

Part III's broadest scope: any system of multiple agents each satisfying the agency scope condition and interacting through a shared environment. Each agent has its own model and purposeful substate; each observes the environment and other agents' actions; each acts; their actions jointly determine the next environment state. *Coupling goes through the shared environment, not through direct state modification* — agents affect each other by affecting the environment.

The framework names a methodological default: **correlated observations are generic, independence is special**. When agents share an environment, their observations are generically correlated — they see aspects of the same reality. Most multi-agent settings of interest involve substantial observation correlation.

Each agent's observation decomposes into environmental and *inter-agent* components — messages from other agents. The **multi-agent routing structure** is a key new object: the *topology* (who communicates with whom) plus the *protocol* (the rule governing what class of information flows between agents). The protocol is a *rule specifying the channel*, not the content of any message. Individual messages reflect senders' states (including individual goals) through their policies. What the routing structure governs is the *infrastructure* — which channels exist and what kind of information they carry. **Routing is goal-blind** when neither topology nor protocol depends on the composite's goal state — the communication infrastructure does not change based on what the composite is trying to achieve. *Goal-dependent routing* (crisis-specific channels, mission-specific intelligence-sharing protocols, reorganizing reporting chains based on objective) breaks goal-blindness.

The framework draws a *load-bearing scope distinction* between two classes of machinery. **Agent-level machinery** (individual persistence, agent tempo, per-agent mismatch, sector-condition stability) applies to *every* agent in *every* multi-agent configuration — cooperative, adversarial, or indifferent — because each agent individually satisfies the agency scope. **Composite-level machinery** applies only when the composite scope condition (in the next segment) is satisfied. The adversarial regime spans the negative-teleological-unity end of the unity spectrum, and is treated *both* ways: equilibrium-convergent adversarial pairs are captured by composite-level machinery (a strategic-composite route); cyclic or non-convergent adversarial dynamics are captured by agent-level machinery applied across the pair.

The routing/content distinction matters for directed separation at the composite level. *Individual messages reflect senders' goals — that's just action through policy.* The directed-separation question at the composite level is about the *routing structure*: does the infrastructure change based on the composite's goals? Goal-blind routing preserves directed separation at the composite level; goal-dependent routing breaks it.
