# Class Coercion via Wrapping (derived — conditional)

A *constructive* result of substantial practical importance. The framework shows that a Class 2 or Class 3 (Coupled) component whose forward pass entangles belief-update and goal-conditioning *can be embedded inside an external scaffold* whose state is updated by *structurally distinct query channels*: **goal-blind queries** to the component update the wrapper's model; **goal-conditioned queries** update the wrapper's purposeful state. Under stated conditions, directed separation holds at the wrapper level *by construction*, and the composite system is Class 1 (Separated) — even though the underlying component is not. This is the constructive direction of the directed-separation-under-composition hypothesis: a procedure for *making* directed separation hold when the underlying component does not provide it.

The wrapper has four type-signed components: a *belief-side query selector* that chooses the model-update query from belief and observation only — *no goal argument*; a *strategy-side query selector* that may depend on the goal; a *belief-update map* that updates the model from the prior belief, observation, the query made, and the component's response — *no goal argument*; a *strategy-update map* that may depend on the goal. The wrapper makes at least two component calls per macro-step: one goal-blind call to update the model and one goal-conditioned call to update the purposeful state.

The result requires three conditions on the component. **(C1) Goal-blind admissibility**: the component's interface admits non-trivial goal-blind queries. The framework partitions components: *Class A* are goal-blind by design (POMDP belief-state filters, world models, sensory pipelines, retrieval systems); *Class B* admit goal-blind query modes alongside goal-conditioned ones (LLMs in summarization or fact-extraction modes; hybrid RL agents with separable value/policy); *Class C* are fundamentally goal-conditioned (pure end-to-end goal-conditioned policy networks) — the construction does not apply. **(C2) Stationary component conditional**: the component's output distribution conditional on input is fixed during operation (adaptation-during-deployment systems are out of scope). **(C3) No implicit goal-inference**: the component's response to a goal-blind query does not depend on the goal via inference from query patterns. For pretrained components like LLMs, (C3) holds *exactly* only when query content is statistically independent of the goal in the pretraining distribution.

The framework offers **two theorems**. **Theorem 1 (exact form)**: under (C1)-(C3), directed separation holds *exactly* at the wrapper level. The wrapper is Class 1 (Separated) by construction. The proof identifies all paths from goal to belief-update and shows each is closed by the type signature or by (C3). **Theorem 2 (approximate form)**: if (C3) is weakened to a KL-leakage bound (small but nonzero leakage from goal to belief-blind response), the wrapper-level leakage on belief updates is bounded by the same bound. The approximate form gives a quantitative robustness: small leakage in produces small leakage out.

The framework names three **wrapping regimes** of decreasing strictness. **W₁ (strict)**: separate goal-blind queries and goal-conditioned queries; structural separation holds at the query boundary; leakage bounded structurally by pretraining-induced mutual information. **W₂ (partial)**: one goal-conditioned call per macro-step, response parsed into typed update fields; structural separation lives at the *write boundary*; the *query boundary* still passes the goal; separation at the wrapper level is *behavioral* — bounded by the component's compliance with the prompted instruction-to-separate. **W₀ (degenerate)**: no separation between belief and goal in the wrapper interface; behavior depends entirely on component compliance.

The result is *load-bearing for the framework's treatment of LLM agents*: an LLM is internally fully coupled (Class 3), but an LLM-agent *system* (LLM + tools + memory + monitoring) can be designed with modular topology that recovers Class 1 status at the system level. The framework's claim is that this is *necessary* (not contingent) for AAT-grade behavior in a Class 3 substrate. The price is paid in *more component calls per macro-step* (the Brooks's-Law tempo overhead from the previous segment) and a *residual leakage rate* bounded structurally (under W₁) or behaviorally (under W₂).
