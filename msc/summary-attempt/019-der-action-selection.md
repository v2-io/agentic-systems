# Action Selection (derived — exact within Part I scope)

The second derived result that falls out of the completeness commitment: action must be a function of the agent's model. Under Part I scope, where $M_t$ is the entire internal state, the agent's action is given by a policy $\pi(M_t)$ (deterministic) or $\pi(\cdot \mid M_t)$ (stochastic). The argument mirrors the recursive-update derivation: since the agent's internal state is by definition complete, action — which depends on internal state — is forced to depend only on that state. Any dependence of action on the chronica is captured automatically *through* the model. The Part II lift, where the internal state expands to include a purposeful substate, gives $\pi(M_t, G_t)$ by the same completeness argument applied to the larger state.

This segment is also where the framework introduces a distinction that recurs throughout the work: **implicit** versus **explicit** action selection — what the segment calls *action fluency*. An agent has high fluency when effective action flows from the model without deliberative computation: the model has internalized the action-selection structure for the current situation. Reflexes, trained policies, expert intuition, standard operating procedures, well-tuned controllers are all instances. An agent has low fluency when deliberation significantly improves action quality — when the situation is novel, the action space large, or the stakes asymmetric, and the agent must use its model to *simulate* outcomes of candidate actions before committing. This requires at minimum Pearl-Level-2 epistemic access (the agent must predict "what will I observe if I do $a$?" for candidates).

A formal characterization is offered: an agent has high fluency when additional deliberation yields negligible improvement in update gain. Fluency is therefore distinct from model sufficiency. A chess engine with a perfect model of the rules still requires expensive search — high sufficiency, low fluency. Conversely an agent can have only moderate sufficiency but high fluency in a narrow domain (a reflex that responds effectively to specific situations it evolved for). What reflexes, muscle memory, intuition, and expertise share is that the action-generating capacity itself has been absorbed into the model's structure: the model doesn't just predict well, it *acts* well, cheaply.

A *structural pressure* toward implicit action is observed: when two modes produce equivalent expected outcomes, the faster mode is preferable, because the persistence condition penalizes slower tempo. Agents under selective pressure (evolution, competition, training) therefore tend to internalize frequently-needed action patterns, converting explicit deliberation into implicit fluency. The pressure is stronger when the environment changes fast, the pattern recurs frequently, or correction capacity is already near the persistence threshold with no slack for deliberation overhead. But deliberation remains essential when situations are genuinely novel, action spaces are large relative to model capacity, stakes are asymmetric, or the environment is stable enough to permit it.
