# The Separability Pattern (appendix discussion — meta-pattern, discussion-grade)

The *positive half* of the framework's scope-honesty toolkit (the identifiability-floor is the negative half). The framework consistently runs a **three-part epistemic posture** across state spaces that admit no tractable exact treatment in general: name the **separable core** where identification is clean; name the **structured repair** that recovers identification under explicitly-added machinery; name the **general open** case where the problem is either intractable or structurally unidentifiable.

The framework catalogs **seven ladders** sharing this shape. (1) **Correlation Hierarchy** in the strategy DAG: L0 independence (separable core, formal results proved) → L1 augmented DAG with strict-prerequisite common causes / L1' mixture form for soft facilitators (structured repair) → L2 full correlation (general open / intractable). (2) **Convention Hierarchy** in value object: C1 one-step improvement (separable core, formal monotonicity proved) → C2 receding-horizon (structured repair, captures multi-step recovery) → C3 Bellman (formal but computationally costly). (3) **Architecture Classification**: Class 1 Separated (separable core, formal results proved exactly) → Class 2 Partial (structured repair, scalar coupling parameter quantifies degradation) → Class 3 Coupled (general open / requires wrapping). (4) **Contraction Tiers** in composition: Tier 1 contraction-on-class (separable core) → Tier 2 locally-convex with degradation (structured repair) → Tier 3 per-domain verification (general open). (5) **Identification Regimes** for edge updates: Regime A intervention-rich (separable core) → Regime B partial intervention (structured repair) → Regime C observation-only (general open). (6) **Scope Cascade**: adaptive (separable core, Part I works) → agentic / actuated (structured repair through scope narrowing) → logogenic / logozoetic (general open at the leading edge). (7) **A2'-sub-scope partition**: $\alpha$ (separable core, derived from gain structure) → $\alpha_2$ (structured repair via adaptive-gain composition under meta-gain conditions) → $\beta$ (general open, sector condition primitively assumed).

The framework names the *complementarity* with the identifiability-floor meta-pattern. The identifiability floor names the **negative content** of AAT's scope honesty (no-goes about what cannot be identified). The separability pattern names the **positive content** (what *can* be done at each tier and what the path forward is when the current tier is insufficient). Together they cover the framework's epistemic posture: *scope-honesty has a positive and a negative half*; both are load-bearing.

The framework's posture: **the three-part structure is what makes scope-honesty operational**. A flat "this result holds under these conditions" leaves the user without a path forward when the conditions fail. The separability pattern says: here is the regime where the conclusion holds; here is the structured repair if you need more; here is the open territory where the problem remains. The diagnostic for moving between tiers is part of the pattern, not an addendum.
