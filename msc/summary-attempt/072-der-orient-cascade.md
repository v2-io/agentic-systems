# Orient Cascade (derived — conditional; ordering exact)

The corrective phase of the cycle for actuated agents expands from a single step into a *multi-step cascade*. The ordering is *not a design choice* — it is forced by information dependency between the diagnostic quantities the framework has assembled. Each step's input depends on the output of prior steps.

The five steps. **(1) Reduce epistemic mismatch** — update the model. This is prerequisite for *all* purposeful evaluation because the model appears in every subsequent formula. **(2) Evaluate the satisfaction gap** — is the goal achievable? Requires an adequate model to assess attainability. **(3) Evaluate the control regret** — is the policy suboptimal? Applied regardless of the satisfaction gap's sign because the 2×2 diagnostic table requires both quantities to distinguish four cases (success / strategy problem / capability limit / both). **(4) If regret is high, evaluate strategy calibration** — is the plan's causal model wrong? This step subdivides: (4a) plan-level calibration via the strategy-plan-confidence error (credit-assignment-free, persistence proved); (4b) per-edge localization via the strategic-calibration residual when sufficient observability and attribution are available; (4c) **causal-sufficiency check** — if plan-level calibration has converged but plan-outcome residuals remain persistently negative, the DAG is causally insufficient and the L0 model is converging to a biased target; the diagnostic is pairwise sibling covariance under exploration; the remedy is L1 augmentation by adding common-cause nodes *before* escalating further. **(5) If the satisfaction gap persists** — escalate before revising the objective: (5a) check whether model correction changes the feasibility assessment; (5b) check whether a richer policy class would close the gap (including L1 augmentation if 4c signaled it); (5c) check whether convention escalation reveals recovery paths (a goal unattainable under one-step lookahead may show feasible under receding-horizon planning); only then (5d) revise the objective.

The cascade ensures **objective revision is the last resort, not the first response to unmet goals**. The agent reaches step 5d only after exhausting the alternatives the satisfaction-gap disambiguation table identifies: wrong model, narrow policy class, short horizon, and only then genuinely infeasible goal. When step 5d is performed by a principal, the revised objective is externally sourced (a standard actuated agent); when *internalized* — the agent performing it on itself — it becomes the self-actuation operator, which (per a conditional no-go in the appendix) is well-formed only under a *grounding* condition: a non-degenerate self-actuator must ground objective-revision on a *non-objective terminal invariant*, not on an objective-functional.

The *inferential force* at each step scales with the value-object continuation convention. Under C1 (one-step improvement, the canonical default), a positive satisfaction gap means *locally stuck*, not *globally infeasible* — a multi-step recoverable objective may appear unattainable because continuation is frozen at the current policy. Under C2 (receding-horizon), the diagnostics capture multi-step recovery potential. Under C3 (Bellman), the gap is definitively global — no policy in the class can achieve the goal. The cascade's *ordering* is convention-independent (forced by information dependency); the *inferential force* at each step scales with the convention used.

The framework names a **virtuous/vicious cycle** between model quality and strategy complexity. *Better model → richer evaluable strategy → better-directed action → faster model improvement.* And the inverse: *degraded model → forced strategy simplification → cruder action → further model degradation.* The vicious cycle is the strategic analog of the death spiral described by the persistence condition — the agent loses the capacity to maintain complex plans, which reduces the quality of its actions, which further degrades its model. The framework names a related complexity bound: *the strategy's evaluable complexity is bounded by the model's capacity* — an agent with poor model sufficiency cannot meaningfully evaluate a complex strategy because the calibration residuals require adequate model to distinguish "edge prediction wrong" from "observation too noisy to tell."

The orient cascade is identified as the *formal analog of Boyd's "Orient"* — the structured interaction between reality-understanding and strategy. Boyd's insight that *Orient is the critical step, not Decide* receives a mathematical mechanism: Orient resolves the information dependencies that make Decide meaningful. An agent that skips to Decide (strategy revision) without adequate Orient (model update plus attainability assessment) will revise its strategy based on stale or incorrect beliefs.
