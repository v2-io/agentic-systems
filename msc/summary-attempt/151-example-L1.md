# L1 Augmented DAG Worked Example (appendix worked example — conditional)

A concrete instantiation of the Correlation Hierarchy on a *two-OR-alternatives sharing an infrastructure dependency* case. The setup: two paths to a goal, both contingent on shared infrastructure being up; if infrastructure is up, the paths have individual success probabilities; if infrastructure is down, both paths fail.

The worked example *exhibits the framework's central observation* about causally-insufficient DAGs. **At L0** (independence model), the AND/OR propagation systematically *overestimates* plan success — the agent's strategy-plan-confidence comes out higher than the actual plan success rate because the model treats the two paths as independently failing rather than as both depending on shared infrastructure. The overestimate's magnitude is exactly the covariance between the paths' outcomes (the framework's central directional-bias result for OR-structures).

**At L1** (augmented DAG with explicit infrastructure node), the propagation is *correct*. The infrastructure node is factored *above* the correlated OR-alternatives as a strict-prerequisite AND-node; conditional on infrastructure being up, the two paths are then independent, and the standard propagation gives the exact answer. The framework's L1 construction principle (factor the common cause above the correlation it creates) is shown to recover the correct probability.

The framework also *verifies the sector condition* for the L1 case. The sector parameter under L1 augmentation has a clean *three-way gating form*: condition-testing rate, evidence-starvation factor on each path, and exploration-gating on the OR-node. Each gating factor reflects a *different mechanism* — how often the agent tests the infrastructure, how often each path is exercised conditional on infrastructure being up, and how the agent allocates exploration across the alternatives. The product gives the composite sector parameter, and the persistence inequality follows by substitution into the chapter's central form.

The example also surfaces the *unobservable-common-cause* failure mode that motivates the L1' mixture form and Cramér-Rao floor result. If the agent *cannot observe* whether infrastructure is up — only the joint path outcomes — the L1 augmentation cannot be done in clean form, and the framework's identifiability-floor Instance 2 result kicks in: the per-conditional decomposition is identifiability-obstructed. The agent's three escape routes (augment observability, run multi-child joint observations, fall back to L0-on-marginals) are *exercised* in the worked example with their respective trade-offs.

The example serves as the **canonical concrete instance** of the framework's Correlation Hierarchy and the L1 construction principle. Where a practitioner encounters correlated failure structure in their own strategy, this example provides the *template* for diagnosing whether L0 is sufficient, when to escalate to L1 or L1', and what the sector parameter and persistence margin look like under each treatment.
