# 04 — New data that would change what can be said

This is what is missing and why, kept at that level on purpose: a different mind designs the next round. Each item names the question the current data can't answer.

1. **Signa (or any control-class sequence) under tie and forced, not only perp.** Without these, a sequence of known intent can't calibrate the study's co-equal question: how much order each format adds. In particular, does the seam that Gemini declines become an ink-ordered seam under forced choice, the way Claude already orders it under perp?

2. **More stimuli of signa's kind: sequences fixed for a functional purpose, by people outside the study, before the study.** One sequence from one author's context can't separate "human-authored" from "this design". Signa's value depends on its having been fixed in advance, so a signa revised in light of these results belongs in the hypothesis-test class, not here.

3. **Human judgments, even a few.** Joseph's control question is ultimately whether these minds see what a human meant. The current data can only say that they depart from the author where the visual gradient departs. Whether a human reader departs at the same seam (`═→⚬`), or reads the circles as continuing the lines, is unmeasured. DESIGN already names a human arm as an optional strengthener.

4. **Within-judge repetitions on the pair instruments**, at least on a subset. Today a flip can't be split into sampling noise vs a slot-resolved tie, except where the conflict battery's three reps exist.

5. **A transitivity measurement that position preference can't produce.** The current cycle statistic is identical to an all-same-slot pattern (`03-instruments.md` §2). Any claim about transitivity, or about capability buying it, needs a unit where intransitivity and slot preference make different predictions.

6. **A baseline for gestalt recovery on arbitrary sets.** Noise foils draw cross-judge-consistent orders, so "recovered at τ = x" means little without "what a generic visual-complexity order would score on this set", plus coverage reported beside τ.

7. **Judge condition as a deliberate factor for ⟂.** The pilot-condition arm shows that harness, context, wording and effort together raise ⟂ use 1.6–1.85× for the same model on the same pairs. The pilot also placed both orders of each pair on one sheet, which v1.0 never reproduced. If ⟂ is to be read as perception, the condition needs to be varied in a way that isolates its parts. If it is to be read as policy, that needs saying in the claims.

8. **gpt-oss-20b and gpt-5.6-terra coverage.** In this copy gpt-oss has no ledger at all, and gpt-5.6 has no perp format data. Several "every frontier judge" predictions are therefore tested on a smaller panel than registered.
