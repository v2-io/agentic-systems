# 02 — The registered predictions, re-derived independently

I re-derived every registered prediction from the raw ledgers. I used the builder's parser p1.3 (`harness/runner/instruments.py`) as the one parse, and my own pairing, scoring and statistics code (`scripts/`). "Committed" means a directed answer. A pair is *consistent-directed* (cdir) when both orders name the same winner. A failed or incomplete sheet row is ignored, and its re-ask is used. When a presentation was asked more than once, the last valid answer is used. Excluded throughout: qwen3-4b (invalid), shakedowns, the grok tool-leak run. gpt-oss-20b has a `spec.json` but **no ledger** in this copy for any instrument, so it contributes nothing. "Frontier" follows PREDICTIONS: the four Claude judges plus grok46, gpt56terra and both Geminis. sonnet55's sheet run is listed separately.

Where the registered wording left a definition open, I say which reading I used. A different reasonable reading can move a borderline verdict. I flag where it would.

## What this says about the MANIFEST claims

- **Claim 3, "format manufactures ~80% of edges".** The direction replicates strongly. For frontier judges, the consistent-directed share of the same 320 pairs goes from 0.64–0.93 under forced and tie to 0.23–0.50 under perp (`tables/format-exp.txt`). The *magnitude* is condition-dependent. Clean API Claude judges dissolve 0.28–0.51 of tie-edges. The same model run as a Claude Code subagent with the pilot wording and the user's global instruction context dissolves 0.58, and says ⟂ on 76% of presentations. The pilot measured 0.80 under a condition that differed from v1.0 in at least two ways. Two differences between pilot and v1.0 are candidates. (a) Condition: harness, user context, wording and effort. The arm's ⟂ use is 1.6–1.85× the clean API judge's. (b) **Sheet pairing.** In the pilot both orders of every pair sat on the same sheet and were answered in one call. I checked a walk2 sheet, and the verifier checked all of them. v1.0 and the arm split orders across sheets. The pilot had about 1% mixed pairs; the arm has 14%. v1.0 can't separate these factors. Stronger point: **the edges that ⟂ removes are not noise.** On pairs one frontier judge dissolves (cdir under forced, consistent-⟂ under perp), the *other* frontier judges' forced-choice winners agree with that judge's forced winner 83% of the time (4758/5727; chance 50%; surviving edges 96%) (`tables/manufactured-edges.txt`). "Manufactured" should be read as **"a weaker ordering, shared across model families, that the ⟂ option suppresses"**. Cross-family agreement alone is 0.83, and 0.82 with every numeric glyph removed. That rules out idiosyncratic noise. It does not rule out construction-on-demand by a heuristic all the families share. The instrument can't say whether the shared ordering is felt but sub-threshold, or constructed.
- **Claim 4, "local transitivity; capability buys discipline".** The registered cycle statistic can't carry this claim as stated (see `03-instruments.md` §2). Every orientation set is cyclic (AB, BC, CA), so every 3-cycle in a set is, *by construction*, the same slot winning all three times. A *high* cycle rate can therefore come from slot preference: sonnet5 has P(first | dir) 0.33 and cycle rate 0.17. It can also come from stimulus-independent answering: gemma and llama show no aggregate slot bias and have rates of 0.23 and 0.12. A *near-zero* rate is still informative. The pilot's "37%" is open to the same reading: its llama triad run used cyclic sets throughout, with P(first | dir) = 0.763 and a cycle rate of 0.369 (verifier, `verification/scripts/vpilot_triads.py`). Requiring all three pairs to be consistent across orientation sets gives order-debiased transitivity, and there are **zero cycles for every judge where it can be measured**: frontier 0/48–0/94 triads, llama 0/33, gemma 0/8 (`tables/triad-transitivity.txt`). Stable-but-arbitrary preferences would give about 25%. So order-stable judgments are transitive at every tier where any exist. For small models, those triads are a small, selected subset (llama 33, gemma 8, qwen25 0), and transitivity elsewhere is unmeasured, not shown equal. What the data clearly show capability buying is **order-stability and ⟂ use**. The "two axes" half holds at frontier (value .95–1.00, ink .64–.83). The number axis fails at 3–4B, as the builder's counter-prediction said.
- **Claim 5, "immediacy arbitrates".** Value wins wherever there is a compiled decode (P9), and ☷ > ⚌ replicates unanimously. The weak-decode case (per-mille) does **not** replicate. It splits by model family, and the pilot's single family happens to be the one that goes to element count. Equal-line grams and the equal-value probes are judge-dependent.
- **Claim 2, "holistic / authored".** The pilot signatures largely fail to replicate as stated.
  - **Drain.** The pilot's exemplar of *authored* ("does not reconstruct; each judge self-consistent on a different path") now **reconstructs**, with full-length exact reverses of Joseph's order from gemini31pro on 3/3 shuffles, opus55, sonnet55 and gemini38flash on 2/3, and gpt56terra on 1/3. Judges are *not* self-consistent across shuffles. Their other answer is mostly one specific alternative: the author's three strata in reversed stratum order, each stratum's internal order kept (`⚊⚋⚌⚍⚏☰☱☳☷`, from opus55, sonnet55, gemini38flash and grok46 ×2). haiku45 instead keeps the trigrams and sends digrams and monograms to EXTRA (|τ| = 1 by exclusion: the same artifact as with signa).
  - **Unfold and risebar.** The holistic signature (pairwise ⟂-heavy, gestalt-recoverable) holds for some judge × set cells and not others.
  - **Noise foils.** The pilot's 36/36 ⟂ "honesty floor" does not hold (0.64).
  - Signa (`01-signa.md`) and the drain are both Joseph-authored and both have a seam, and the judges treat the two seams differently. The drain's seam `☷→⚌` is carried by line count: `☷ > ⚌` is unanimous in the conflict battery. It is *not* carried by rendered ink, which in Ghostty rises at that step (0.084 → 0.095; the pilot's "ink strictly decreases" does not hold in this rendering). Signa's seam `═→⚬` goes against every visible quantity at once: smaller, thinner, lighter. Judges follow the first and leave the second. That is two cases, so it is suggestive, not a rule.
