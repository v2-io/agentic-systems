**Status: restarting. No claims.** The earlier claims rested on magnitude-framed pilot and v1.0 data, which are archived at Joseph's request (`.archive/2026-10-04-magnitude-era/`, with a README). The previous MANIFEST is there as `MANIFEST-2026-10-03.md`.

## What it studies

Which glyph sequences LLM minds perceive. Sequences are unoriented (direction-free) linear orders over glyphs, within and across glyph families, and need no named axis. The study also asks how widely each sequence is shared across LLM families. Magnitude and direction are no longer central (Joseph, 2026-10-04).

The co-equal object is unchanged: how the measurement format and context manufacture or suppress the order a mind reports.

## Method

`METHODOLOGY.md` (since 2026-10-05): glyph sequences as a context tree, built from conditional-continuation answers and tested by recognition questions with matched controls, over minds of several LLM families. `CATALOG.md` is the one stated model that reads sequences off it (designed, partly built). `HANDOFF.md` holds the current state and open threads.
