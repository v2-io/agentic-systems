# Why a chat-trained LLM is Class 3 has a sharper reason than canon states: the coupling begins upstream of processing, when an input's type is assigned. A user's correction of their own earlier request is goal and evidence on one channel at once, so no downstream goal-blind query can be clean unless the channel is typed first. Canon's neighbours cover adjacent ground (#def-coupled-update-dynamics, the system prompt carrying G_t; #der-logogenic-as-wrapping:51-53, goal inference from query content and system-prompt contamination) but not this. The same build found two facts the TRACTUS-to-CHRONICA mapping in #def-chronica's Working Note (lines 42-51, an open question) needs: thinking in a transcript is a substrate-produced summary of interiority, not the interiority; and much of what enters M_t is harness-channel content (project instruction files, the system prompt, reminders), which a chronica must type separately or it blurs directed separation. A design consequence Joseph drew (the user channel feeds the agent's model of the user, CONSORTIA, never its goals directly, so sycophancy, prompt injection and misread intent each change category) is 04-eli and logos material.
