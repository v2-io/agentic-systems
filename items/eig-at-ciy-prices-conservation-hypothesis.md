# Hypothesis to attempt: EIG quality at CIY prices is conserved. CIY was chosen over expected information gain because it is computable from the current model while EIG needs a meta-model (#def-causal-information-yield's open-direction paragraph). Query actions then look like cheap exploration ('a single query worth a thousand probes'), but only after the query is formulated, and formulating a well-formed query requires knowing what one does not know: EIG's cost reappears in the query channel (and in lambda's heuristicity, and in trust). Candidate statement: no agent obtains EIG-quality exploration at CIY cost; the difference is paid in formulation, in a heuristic lambda, or in trust. Either a conservation result or a no-go.
