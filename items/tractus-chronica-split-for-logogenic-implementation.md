# Decide where the TRACTUS/CHRONICA distinction gets first-class treatment: PROPRIUM separates TRACTUS (raw, plural, per-substrate record of runtime-substrate API traffic: retries, reroutes, error recoveries) from CHRONICA (the entity's singular, attested, hash-chained record). Part I's #def-chronica abstracts over both, which is right for Part I. Joseph, 2026-05-01: 'whether or not def-chronica needs that distinction at this stage or when we get into logogenic agent implementation issues is the open question you should probably document.' The note's probable answer is a Volume 3 definition (def-tractus or similar) under #scope-interiority-loop, leaving Part I alone. A forcing use case was proposed 2026-08-12: incident forensics as a two-primaries record architecture, where divergence between the layers is the diagnostic (the 2025-09 tool_use-stripping incident was visible only at the transport layer).
