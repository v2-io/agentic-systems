# #result-persistence-condition's Epistemic Status says 'The threshold's existence is robust qualitative: any monotone correction function has a capacity limit; this holds across all correction functions tested.' The same segment's Formal Expression ('Linear case') has the monotone linear corrector F = T delta with R -> infinity, so as a statement about functions it is false. What may be true is a descriptive claim that real correctors saturate, and the evidence for it is the Part I simulations of the theory's own correction functions. Restate it as that claim, at its tier, or delete it.
