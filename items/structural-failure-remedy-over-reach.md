# Structural failure is said to need a new architecture, and the segments' own window refutes that. #result-persistence-condition (opening, task-adequacy paragraph) says 'structural failure requires changing the correction architecture entirely', and #result-sector-condition-stability (opening; Discussion 'Connection to structural adaptation') says crossing rho/alpha > R 'requir[es] a new model class with larger valid radius R' or better efficiency alpha''. Both are false for correctors the same segments treat. Under Model S with white channel noise, a linear corrector whose gain is above alpha_+ fails structural persistence and is restored by lowering its gain on the same architecture. When R^2 <= n sigma_env sigma_nu, better observations restore it, and the body files those under task-adequacy remedies. Under Model D, raising alpha where the architecture allows it also works. So structural failure has at least three remedies (retune the gain, add information, enlarge R or alpha by a class change), and the new model class is needed only when capacity binds at every admissible gain. Also in #result-sector-condition-stability: 'When rho/alpha > R … the sector condition fails' is wrong, because the sector condition is a property of F on B_R and does not depend on rho; what fails is the certificate. Strengthen first: state the remedy set the window derives. The 'new model class' case is the capacity-bound one #result-structural-adaptation-necessity treats.
