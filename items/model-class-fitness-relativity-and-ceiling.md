# #def-model-class-fitness writes F(M) = sup_M S(M) as a property of the class. S is policy-, trajectory- and task-relative and undefined in predictively vacuous regimes, and F inherits all of it without saying so (526815, 584721, 742613 converge). Line 28 says the gap 'cannot be closed by better parameter estimation, more data, or longer training within the current class'. That is true of an asymptotic ceiling, not of F computed on the current finite chronica (742613). One sentence stating the inheritance, and one distinguishing the current estimate from the asymptotic ceiling, would close both; #result-structural-adaptation-necessity, which rests on F, needs the asymptotic reading.
