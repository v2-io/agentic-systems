# #scope-ciy-observational-proxy, two points checked at HEAD 4175aae7. (a) The proxy (line 25) conditions on Omega_t. If that is the true state, the formula is a population-level identity, not something computable from observations; if it is an estimated state, the formula should say so and carry model-error caveats (526815; 963715). (b) Lines 19 and 43 say software development is typically Regime A. For an LLM software agent that holds within a session but not across sessions, where attributing codebase changes to downstream effects needs assumptions, so its typical regime is B. The regime table should distinguish software as a domain from an LLM agent in software as the unit (963715, lifted 2026-08-22 via #impl-causal-access). Source: gold Follow-ups (WN lines 76, 78).
