# #der-action-selection defines action fluency on one quantity and uses it for another, and conflates deliberation with lost tempo (checked at cbd2f345). (a) :17, :49 define fluency as Delta eta*(Delta tau) ~ 0 (update gain), while the examples (chess search, MCTS, MPC, :51) are about action quality, and :49's last sentence defines fluency as action quality. 731548 certified the fix ('one inherited caveat clause ... or the honest retitle epistemic fluency', audits/.integrated/AUDIT-WORKING-731548/27-der-deliberation-cost.md:4; ledger xliv); #der-deliberation-cost already carries the epistemic-only caveat this segment omits. Not in the 731548 FINAL; 742613's earlier flag was deferred. (b) :19, :53 'the persistence condition penalizes slower tempo': tempo is a rate of update events, and an agent that withholds action can keep observing and updating; deliberation costs persistence only if it competes with updating. The same conflation is in #der-deliberation-cost's step 2. (c) Stale gold, WN :85: 'Deliberation is only necessary when the Separation Principle fails', endorsed by 731548 as 'verified and genuinely deep'. Chess is fully observed (separation trivial) and still needs search; what spares LQG is certainty equivalence and the absence of a dual effect (Bar-Shalom and Tse 1974, already cited in #der-directed-separation; finder 16, not checked at the primary).
