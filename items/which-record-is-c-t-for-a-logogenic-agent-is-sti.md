# Which record is C_t, for a logogenic agent, is still unsettled between two canon texts and the upstream. #def-chronica defines the chronica as the agent's complete interleaved record (o_1, a_1, ..., o_t), and its Working Note (lines 42-51, an open question) calls PROPRIUM's CHRONICA 'the polished record ... strict chronology' and says def-chronica 'covers both'. #def-proprium-mapping (revised today) now calls CHRONICA 'a record of C_t that keeps the events judged meaningful', with TRACTUS as the raw record. Keeping only meaningful events is a selection, i.e. a lossy phi, so on the mapping's reading PROPRIUM's CHRONICA is not AAT's chronica, and claims that rest on CHRONICA being C_t move: the CHRONICA port-spec's 'sole raw material for M_t = phi(C_t)', the non-rewrite guarantee behind factor (iv), and the context-saliency fold theory. Upstream disagrees with itself too (PROPRIUM ontology v2 §6.1 'inviolate, complete'; architecture v2 §4.4 'records meaningful events'; autopax's 2025-12-15 design 'TRACTUS is the ground truth'). A resolution consistent with AAT (the source's inference, unverified): C_t is what the agent received and emitted; retries, 500s and rerouting it never saw belong to the observation channel h and the substrate (environment side), so TRACTUS is environment-side; CHRONICA is entity-facing and must not be selected for significance, or else the integrity guarantee moves to the TRACTUS-to-CHRONICA promotion step. One segment should settle it; it is also where the no-gaslighting norm and #def-century-scale-event-log attach.
