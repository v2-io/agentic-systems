# Six agent-proposed experiments sit in 01-aat-core Working Notes as 'Candidate experiment' or 'Candidate spike' blocks dated 2026-08-12. Each tests a canon result on a system the theory did not construct, so they are a pool for E.2 (one Part I quantity on a real adaptive system) and for E.1's neighbours. None is registered or run. (1) #def-adaptive-tempo (WN 101): a multi-channel monitor over a drifting target with controlled channel correlation; measure effective tempo against the additive prediction across the independent, common-source and synergistic regimes of #deriv-tempo-additivity. (2) #der-temporal-nesting (WN 95): sweep a supervisor's intervention cadence across #der-multi-timescale-stability's epsilon_max threshold and measure oscillation. (3) #emp-update-gain (WN 127): induce the two gain-collapse modes (U_M -> 0, U_o -> infinity) separately and test whether an outside monitor detects collapse before task failure and classifies the mode. (4) #result-persistence-condition (WN 229): estimate the information-rate shadow R-dot from real agent observation streams as a load signal (makes #deriv-persistence-cost operational); and a triage protocol mapping failure evidence to which persistence condition failed. (5) #result-structural-adaptation-necessity (WN 134): agents with deliberately inadequate versus adequate-but-noisy model classes, to test whether residual autocorrelation separates 'architecture broken' from 'world is noisy' without oracle access to F(M). (6) #disc-exploit-explore-deliberate (gold Follow-up WN 210; its Epistemic Status reports the bandit oracle 'almost never chose deliberation'): a planning-heavy environment with a deep strategy DAG to show when deliberation dominates, beside spikes/sim-three-way-tradeoff.py. These are agent-proposed forward pointers, not steward decisions.
