# #deriv-strategic-composition's sub-scope alpha' transfer is overclaimed, re-read at HEAD 86489b0b (526815 F234-F240, F243; the internal-surfaces map verified the core of it at 7d3e203). (F234-F236) Lines 48-52 derive dPhi/dt >= alpha_joint ||grad Phi||^2 from the potential-game condition plus B1 fidelity. That ascent inequality is fine. The paragraph then says 'the sector-persistence template transfers with xi = pi - pi*' and 'equilibrium stability follows from Phi's role as a joint Lyapunov function'. Neither follows. Potential ascent can end at local maxima, saddles, boundary or multiple equilibria, and the state variable switches from grad Phi to pi - pi* without the curvature (PL / strong concavity) relation that maps one to the other. Strengthen first: state alpha' exact transfer under a PL or strong-concavity hypothesis on Phi near the selected equilibrium. The Cournot instantiation (lines 94-117) already supplies that curvature (526815 F244), so the witness for the strengthened scope is in the segment. (F237) Line 64: 'Pure-strategy Nash equilibrium existence is therefore guaranteed for ... continuous payoffs'. Hartman-Stampacchia gives a VI solution; that solution is a Nash equilibrium only under concavity (quasi-concavity, Debreu-Glicksberg-Fan) in each player's own strategy and differentiable payoffs. (F238/F240) Line 68 says no-regret -> CCE 'requires no structure on the game beyond each sub-agent computing its own regret'; it needs bounded payoffs and the stated protocol. (F239) Line 48 uses #der-gain-sector-bridge, which is not in depends. (F243) Line 192 says active inference 'fails here in a derivable way', more than the segment derives. F241 (the C-iv 'Proposed Scope' tag, line 121) is item:todo-613842-c-iv-idiom-drift-integration-debt-e3af. 193847's 'C-iv produces a Class-3 composite' reading is superseded in canon (line 181: dynamic-regime transition, architectural class preserved).
