# #hyp-truth-serving-loophole's open premise has a standard formal handle and a named failure mode that canon never connects (MAP D15). The segment's Working Note (line 55, HEAD cbd2f345) asks whether 'calibration of M_t against realized events' is a value functional in #form-objective-functional's sense. Strictly proper scoring rules are exactly that object: an expected score uniquely maximized by reporting one's true belief (Savage 1971; Gneiting and Raftery 2007, JASA), and AAT already uses one, the log-loss of #deriv-mismatch-budget-attribution (line 70), without saying so. The named failure mode is performative prediction (Perdomo, Zrnic, Mendler-Duenner and Hardt 2020, ICML): when the agent's predictions or actions move the outcomes it is scored on, a calibration objective can be served by changing the world rather than the model, which is the loophole's own worry in formal dress. Strengthen-first: attempt the premise with these (is a strictly proper score on realized events a value functional, and does it escape #def-value-object's convention relativity?), and state performative stability as the condition under which the loophole closes or opens. Adopt both under their original names, with citations checked against the primaries (they come from the source writer's training).
