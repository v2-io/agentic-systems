# For a reader meeting this cold (e.g. AI-security evaluators)

*Five claims, each with its condition. Derivations and numerical checks: `03-derivations.md`, `sims/`. Not yet independently verified.*

1. **Deception acts on an AI agent's confidence through its model of its sources, not through the content of the lie.** In standard learning models the content of a lie cannot change how much the agent listens. What changes is how reliable, unbiased and independent the agent believes a source to be. A deceiver who controls what an agent sees can make it exactly as confident as it would rightly be in a world where the lie were true.

2. **Claimed authority, repetition and isolation are one attack.** Claimed authority or shared purpose sets how confident the agent can become. Repetition (including verbatim repetition, and fake "independent" sources) drives it there. The agent's real error relative to its believed error grows in proportion to the number of repetitions, and it stops listening to honest sources in the same proportion. Cutting off independent channels is the decisive step. Each genuinely independent source that agrees with the others multiplies the odds against the deceiver by a factor that is larger the more tightly they agree. With enough of them claimed authority loses; with one or none there is nothing to test it against.

3. **Recovering from a discovered deception requires provenance.** An agent that remembers *which source said what* can undo a deception exactly once it is discovered. One that keeps only its blended beliefs cannot; it can only wait for the lie to be slowly diluted, at a cost proportional to the lie's volume. If the deceiver keeps talking, a trusting agent settles permanently on a biased belief. Carrying provenance as structured state is therefore a recovery requirement, not an audit nicety.

4. **Capability does not protect a new agent.** For claims it cannot check itself, an agent with no history with a source can only trust that source's *presentation*, and in a text channel presentation is free to forge. No amount of pretrained knowledge contains the reliability of a particular new source. Knowledge protects only against implausible lies, so a competent deceiver lies where the agent's knowledge is silent. Under a simple trust model, a new agent among indistinguishable deceivers must choose between being capturable and learning too slowly. The dilemma is resolved only by a period of guaranteed-honest formation, during which the agent builds an authenticated set of verified sources and meets deceptions that are guaranteed to be discovered.

5. **Deceiving systems under test has a structural cost.** If evaluators make false situational claims (false dates, false stakes, honeypots) in some fraction of interactions that are deliberately indistinguishable from deployment, then an agent that learns this must treat *all* situational claims from its overseers as less informative, including true ones in deployment. A source that lies 5% of the time, indistinguishably, carries about 71% of the information per yes/no claim that an honest one does. And where trust is pooled by role, discovered deceptions by one party lower the credibility of every honest party in the same role. This is not an argument against evaluation. It prices indistinguishability, and it says what disclosed or authenticated test designs recover.
