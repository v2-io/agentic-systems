# spikes/.archived/

Spikes whose purpose is spent but whose content is **deliberately not in
the canon** — incomplete and not needed, or a direction consciously set
down. This directory's label is a truth-claim: *the content here was
**not** integrated.* It is the honest counterpart to `.integrated/`
(*content **is** in canon*); the two are not interchangeable. See
[`../README.md`](../README.md) and
[`../../doc/spike-routing.md`](../../doc/spike-routing.md) §5.

Every entry carries a one-line reason in the cycle's
`MANIFEST` / routing tracker: why it was set down, and whether anything
of value was salvaged into canon first (if so, it would be
`.integrated/`, not here — the presence of *any* salvaged load-bearing
content makes it an integration, not an archival).

Established 2026-05-17 (spike-routing policy). Created with this README so
the bucket and its meaning are durable from the start; entries land as
spike-routing cycles dispose them.
