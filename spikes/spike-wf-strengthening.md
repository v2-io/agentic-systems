## 1. The gap, restated exactly (so the target is unambiguous)

The independent audit of `spike-self-actuation-grounding.md` found Claim WF
(that spike's §2.1) sound *only* to the following strength:

- Non-degeneracy $\Rightarrow$ the admissible set
  $\mathcal{O}_{\mathrm{adm}} = \mathrm{range}(\mathfrak{A})$ is a **proper**
  subset of all objectives, carved out by a membership predicate
  $\chi:\mathcal{O}\to\{0,1\}$ that is not the degenerate "is
  $\delta_{\text{sat}}$ small" selector.

The §2.1 move *"anything held constant across the map and used to admit
objectives **is** a functional held fixed/monotone … there is no third thing.
$\square$"* silently upgrades a **set-membership indicator** into an
**ordered/monotone potential** $\Phi$. The audit's objection is exactly right
at this strength:

> Inside a fixed admissible set the agent can wander or cycle
> ($O\to O'\to O''\to O$) with no conserved ranking. $\chi$ is constant
> ($\equiv 1$) on every admissible meta-trajectory, so
> "$\Phi(O_t')\succeq\Phi(O_t)$" is vacuously true and **does no work**: a
> constant indicator is not "a value functional one level up" in any sense
> that makes the §2.2 recursion bite.

The strengthening target is therefore precise: **show that non-degeneracy
forces a conserved/monotone object with enough order structure that WF
re-applies at level 1** — or find the clean no-go (non-degeneracy provably
does not force more than a set) and state exactly where it breaks.

The decisive observation about the *original* argument: §2.1 used only that
$\mathrm{range}(\mathfrak{A})$ is a proper subset. It never used the
**dynamics of revision**. A fixed set is the *static shadow* of a constraint;
a monotone potential is a *dynamical* object. So if a strengthening exists, it
must come from the revision dynamics AAT already commits to — not from set
algebra. It does. The dynamics is the orient cascade.

## 2. The structural facts the original argument left on the table

All three are already in the theory, primary-source-verified against the
segments:

**(F1) Step 5 of the orient cascade is a *guard on when $\mathfrak{A}$ fires*,
and the guard is exact.** `#der-orient-cascade` step 5: revision of $O_t$
(step 5d = $\mathfrak{A}$) is reached *"only after exhausting the alternatives
… wrong $M_t$, narrow $\Pi$, short $N_h$, and only then genuinely infeasible
goal."* Step 5d fires **only if** $\delta_{\text{sat}}(O_t)\gt 0$ persists
across 5a ($M_t$-correction), 5b ($\Pi$-expansion incl. L1 augmentation), and
5c (convention-escalation C1→C2→C3). `#der-orient-cascade` Epistemic Status:
*"The cascade **ordering** is exact: it is a logical consequence of which
quantities appear in which formulas."* So "$\mathfrak{A}$ may fire on $O$ at
$M_\tau$" is not advisory — it is a **predicate**
$\mathrm{Lic}(O, M_\tau) \in\{0,1\}$ that is *exact*, reading: "$O$ is
confirmed infeasible at $M_\tau$ — $\delta_{\text{sat}}(O)\gt 0$ under the best
model, the richest reachable policy class, and the strongest convention."

**(F2) The degeneracy boundary is sharp and is about the *selection
rationale*.** `#def-satisfaction-gap` §1 (and the spike's own §1): the
degenerate move is to return the $O'$ whose $V_{O'}^{\min}$ is met by the
trajectory *already in flight* — drive $\delta_{\text{sat}}\to 0$ "by moving
the target onto the arrow." `#def-control-regret`'s 2×2 makes this exact: the
only cell that licenses *objective* revision is **capability-limit**
($\delta_{\text{sat}}\gt 0$, $\delta_{\text{regret}}\approx 0$) — *after*
$M_t/\Pi/N_h$ are ruled out. Non-degeneracy is therefore *not* a statement
about the admissible set's cardinality; it is the statement that **the reason
a revision is admitted is confirmed-infeasibility, never gap-vanishing**.

**(F3) The interface is scalar and totally ordered, and the agent must act.**
`#form-objective-functional`: $O_t$'s sole handle is
$V_{O_t}:\text{traj}\to\mathbb{R}$ — codomain *totally ordered*; Epistemic
Status §1 (revealed preference): an agent that acts has implicitly scalarized;
one that "truly cannot compare alternatives … is stuck, not purposeful." The
order structure a monotone potential needs is *already* a load-bearing AAT
commitment, not something this spike must import.

**(F4) The trajectory is singular and non-forkable.** `#scope-agent-identity`:
the objective-sequence $(O_t,O_{t'},\dots)$ along $\mathcal{C}_t$ is
well-defined and non-forkable. This is what makes "the admissible-continuation
correspondence along $\mathcal{C}_t$" a well-typed object rather than a
branching tree with no canonical history.

The original §2.1 used none of F1, F2-as-rationale, F4. The strengthening is
exactly: *use them.*

## 3. The strengthening

### 3.1 The right candidate for $\Phi$ (the audit's objection lands on the wrong one)

The audit's "constant indicator $\chi$" objection is correct **and** it is
aimed at the wrong object. $\chi$ (membership in $\mathcal{O}_{\mathrm{adm}}$)
*is* vacuous as a potential — the audit is right. But the conserved object the
recursion needs is **not** $\chi$. It is the **selection functional**: the
rule by which $\mathfrak{A}$ picks the next objective. The spike's own
(b-grounded) branch already glimpsed this for the fixed-point case
("the terminal grounding invariant is the fixed-point *selection rule*
itself"); the strengthening is to see that this is **general**, not special to
fixed points, and to give it the monotone structure F1 supplies.

Define, along $\mathcal{C}_t$ (well-typed by F4), the **admissible-continuation
correspondence**

$$\mathcal{K}_t \;=\; \Big\{\,(O_t,O_{t'},O_{t''},\dots)\ :\ \text{every transition } O_{(k)}\to O_{(k+1)} \text{ is cascade-licensed by the realized } M\text{-stream, i.e. } \mathrm{Lic}\big(O_{(k)},M_{\tau_k}\big)=1 \text{ and } O_{(k+1)}\in\mathcal{O}_{\mathrm{adm}}\,\Big\}.$$

and the **selection functional**

$$\Phi(\sigma)\;=\;\begin{cases}\big(A_O(M_\tau;\Pi,N_h)\big)_{\tau}\quad(\text{the realized value-attainment stream along }\sigma) & \sigma\in\mathcal{K}_t\\[4pt] -\infty & \sigma\notin\mathcal{K}_t.\end{cases}$$

$\Phi$ has *exactly* the `#form-objective-functional` type signature with
"trajectory" instantiated as "objective-sequence" (this is what §2.2 asserted)
— but now with the two properties that make it a *monotone potential* rather
than a constant indicator, both **derived** below.

### 3.2 The exhaustive dichotomy (this replaces "there is no third thing. $\square$")

Take any non-degenerate $\mathfrak{A}$ and any realized meta-trajectory it
produces. Consider an arbitrary transition $O\to O'$ in it. Exactly one of:

- **(i) Cascade-licensed.** $\mathrm{Lic}(O,M_\tau)=1$: $O$ is confirmed
  infeasible at $M_\tau$ (5a–5c exhausted, per F1), and $O'\in\mathcal{O}_{\mathrm{adm}}$.
  The switch was *forced through the guard by the realized model*, not chosen
  freely. It is a **commitment**: having honored it, re-admitting $O$ later
  *without a feasibility-relevant $M$-change* is precisely the F2 degenerate
  move (re-targeting with no new evidence). Hence each licensed transition
  **removes** meta-trajectory continuations from $\mathcal{K}_t$ and adds
  none.

- **(ii) Not cascade-licensed.** $\mathrm{Lic}(O,M_\tau)=0$: $O$ was *not*
  confirmed infeasible, yet $\mathfrak{A}$ switched away from it. The only
  rationale that admits a switch off a not-confirmed-infeasible objective and
  is consistent with $\mathfrak{A}$ being a *self-actuation* operation (it
  acts to reduce its own $\delta_{\text{sat}}$) is gap-comparison over the
  menu: pick the $\mathcal{O}_{\mathrm{adm}}$-member with lower
  $\delta_{\text{sat}}$ *now*. By F2 that **is** the degenerate selector
  restricted to a menu — and §1 of the parent spike already establishes the
  menu being a proper subset does not rescue it, because
  $\arg\min_{\text{menu}}\delta_{\text{sat}}$ still lands on an objective the
  in-flight trajectory satisfies, collapsing $\delta_{\text{sat}}$ pointwise
  along the meta-trajectory. **Non-degeneracy excludes (ii) by definition**
  (§2.1's own definition of non-degenerate).

The dichotomy is exhaustive because $\mathrm{Lic}(O,M_\tau)\in\{0,1\}$ is a
*total* predicate (F1: the cascade ordering is exact, so for every $(O,M_\tau)$
the cascade either does or does not reach 5d). "There is no third thing" is now
**derived** — it is "$\mathrm{Lic}$ is two-valued, and the $\mathrm{Lic}=0$
branch is degenerate by F2" — not asserted. The free-wandering cycle the audit
feared lives entirely in branch (ii), which non-degeneracy forbids.

### 3.3 The monotone structure, now derived

From 3.2: for a non-degenerate $\mathfrak{A}$, **every** realized transition is
in branch (i). Therefore, writing $\sqsubseteq$ for causal-trajectory prefix
extension,

$$\mathcal{C}_t \sqsubseteq \mathcal{C}_{t'}\quad\Longrightarrow\quad \mathcal{K}_{t'}\ \subseteq\ \mathcal{K}_t. \tag{M}$$

(Each branch-(i) transition deletes continuations and adds none — 3.2(i). No
branch-(ii) transitions occur — non-degeneracy. Union over the realized
transitions between $t$ and $t'$ gives (M).)

(M) is the monotone potential. Concretely, $\Phi$ from §3.1 satisfies:

- **(a) Monotone effective domain.** $\mathrm{dom}\,\Phi = \mathcal{K}_t$ is
  non-increasing along $\mathcal{C}_t$ by (M). This is the conserved order
  structure: the agent's *space of admissible futures* only contracts, never
  re-expands; re-expansion is identically the degenerate move.
- **(b) Not the degenerate selector on its domain.** On $\mathcal{K}_t$, $\Phi$
  is the realized attainability stream under cascade-licensed (=
  environment-forced, F1) revision — by 3.2 it is *never* the
  gap-minimizing selector (that is branch (ii), excluded).

(a)+(b) are exactly the working content the disposition asked for —
"preserved or monotone value-functional $\Phi$ across the revision dynamics."
Note the precise form of the monotonicity: it is **not** "$\Phi$-the-scalar is
non-decreasing step to step" (that would be false and is not needed — the
realized $A_O$ stream can go up or down with the environment). It is
"$\mathrm{dom}\,\Phi$ — the admissible-continuation correspondence — is
monotone non-increasing along the non-forkable trajectory." That is the
*correct* sense of "the revision holds $\Phi$ fixed/monotone": it holds fixed
*the rule* and monotonically *narrows the admissible continuations*. This is
the same shape as a Lyapunov **sublevel-set** argument (the set the dynamics
can be in only shrinks) rather than a conserved-scalar argument — and it is
the shape AAT uses elsewhere (`#disc-additive-coordinate-forcing` /
`#disc-identifiability-floor` are sublevel/floor-typed, not
conserved-scalar-typed), so it composes with the framework's existing
meta-structure rather than introducing a foreign one.

### 3.4 Why the recursion now bites (closing §2.2 / §2.3)

§2.2 wanted: "the agent that self-actuates under $\Phi$ **is** an actuated
agent whose objective is $\Phi$ and whose action space includes 'revise
$O_t$,' so WF re-applies at level 1." With $\Phi$ now a value functional with
monotone effective domain (M) rather than a constant indicator, this is no
longer a type pun:

- The level-1 agent's objective is "keep the meta-trajectory in
  $\mathcal{K}_t$" — a genuine $V$-typed objective on objective-sequences
  (F3 gives it the scalar order; the codomain is the attainability stream,
  with $-\infty$ for $\mathcal{K}_t$-exit).
- Its own self-actuation operator $\mathfrak{A}^{(1)}$ (revising the *selection
  rule* itself) faces the **same dichotomy by the same argument**: either each
  level-1 revision is cascade-licensed (its own $\mathcal{K}^{(1)}_t$
  contracts monotonically — 3.2(i)/(M) re-derived one level up, *verbatim*,
  because F1/F2/F3/F4 are level-agnostic), or some level-1 revision is the
  gap-minimizing selector (degenerate, 3.2(ii)).
- §2.3's well-foundedness step then runs **unchanged**: the policy
  $\pi(M_t,G_t)$ is a single finite computation per step
  (`#der-directed-separation`: the dynamical system is exactly
  $f_M,f_G,\pi$ — no out-of-band oracle; F4: single finite trajectory), so it
  consults only finitely many tower levels before emitting $a_t$; the deepest
  consulted level $L$ has no licensed invariant above it that the agent
  actually consults; by the dichotomy at level $L$ the only way $\Phi^{(L)}$
  gets revised with nothing-consulted-above is branch (ii) = degenerate. Hence
  infinite ascent (every level agent-revised, none terminal) $\Rightarrow$
  degenerate. Q.E.D. for Result G.

The audit's specific objection is now discharged at its own strength: the
recursion does not rest on a constant indicator. It rests on a correspondence
whose monotone contraction (M) is *forced* by the cascade guard (F1) plus the
degeneracy boundary (F2) — both of which the theory already carries as exact.

## 4. The honest edge — the strongest residual adversary, named and shown to collapse

The disposition asks for exactly where the strengthening would break, stated as
precisely as a success. There is exactly one place it could, and it does not.

**Vacuous-guard adversary.** Suppose every $O\in\mathcal{O}_{\mathrm{adm}}$ is
*mutually cascade-substitutable*: from any $M_\tau$, for any pair
$O,O'\in\mathcal{O}_{\mathrm{adm}}$, $\mathrm{Lic}(O,M_\tau)=1$. Then "licensed"
is vacuous on $\mathcal{O}_{\mathrm{adm}}$, (M) gives $\mathcal{K}_t$ that never
strictly contracts, and the agent free-wanders inside a non-degenerate set —
the auditor's cycle, resurrected *inside* non-degeneracy. This is the one case
that would sink the strengthening; it must be answered, not waved past.

**It collapses into the dichotomy; it is not a third case.** $\mathrm{Lic}$ is
a function of $M_\tau$ (F1: it is the exact verdict
"$\delta_{\text{sat}}(O)\gt 0$ persists across $M_t/\Pi/N_h$"; and
$A_O(\cdot)=A_O(M_\tau;\Pi,N_h)$ is a function of $M_\tau$ —
`#def-satisfaction-gap`). For the cascade to license $O\to O'$ at $M_\tau$ and
*also* license $O'\to O$ from a next model $M_{\tau'}$ that differs from
$M_\tau$ only by ordinary epistemic update with **no feasibility-relevant
change** ($A_O(M_{\tau'})=A_O(M_\tau)$ for the objectives at issue), the
feasibility verdict on $O$ would have to flip with no feasibility-relevant
input. A verdict that flips with no feasibility-relevant model change was not
driven by $M$ — it was driven by the selector — and by F2 the only selector
that flips the adopted objective on non-feasibility grounds while reducing
$\delta_{\text{sat}}$ is the degenerate one (branch (ii)). So:

- mutual-substitutability **with** feasibility-relevant $M$-change between the
  switches = branch (i) (genuine environment-forced commitments; $\mathcal{K}_t$
  legitimately and strictly contracts — the "vacuous guard" was not vacuous,
  the model really moved);
- mutual-substitutability **without** feasibility-relevant $M$-change =
  branch (ii) (degenerate; excluded by non-degeneracy).

The adversary requires the *without* case to be non-degenerate, and F2 forbids
exactly that. **It is not a third case.** This is the precise analogue of the
parent spike's §6 honest-edge discipline: the one scenario that would make the
strengthening fail is named, and it is shown to be identical to the
already-excluded degenerate branch — not refuted vaguely, refuted *by the
mechanism* (F2 + $A_O$-is-a-function-of-$M_\tau$).

**The genuine scope boundary (inherited, not new).** The strengthening
inherits — and does *not* repair — the parent spike's §6 premise (1): if AAT
ever admits a *primitive reflective oracle* consulted free-of-cost per step,
the finite-consultation step of §3.4 fails and an infinite tower could
discharge in one oracle call. (M) and the dichotomy are untouched by this — it
is the §2.3 well-foundedness step, not WF, that the oracle would break. This is
already correctly scoped in `spike-self-actuation-grounding.md` §6(1) and a
landing segment must carry it verbatim; this spike adds nothing to and removes
nothing from that boundary. The vector-valued-objective edge (parent §6(2))
likewise transfers unchanged: under a Pareto $V_{O_t}$, $\Phi$ retypes from a
scalar-domain functional to an admissibility *correspondence* and (M) becomes
set-containment monotonicity — the strengthening's *shape* (monotone effective
domain) is exactly what survives that retyping, so the §6(2) "scope annotation
not a hole" verdict is, if anything, *reinforced* by this spike.
