## 1. Why this makes the framework clearer

### 1.a The current holding-cell problem (GS)

GS is currently parked in `#disc-separability-pattern`'s
strategic-composition ladder general-open tier as a result of the
2026-05-20 strengthen-first check that correctly *rejected* it from the
identifiability-floor: actor-under-the-no-go is wrong (designer, not
agent); kind-of-remedy is wrong (Bayes-Nash IC / preference-domain
restriction / randomization / subsidies — none currently AAT machinery).

That rejection was honest but it didn't *land* GS anywhere — it parked
it. The parking is precisely the symptom this meta-segment resolves.

### 1.b The missing taxonomic category

The constructive-impossibility *meta-shape* doesn't care whether the
actor is the agent or the designer. What it cares about is the
*epistemic discipline* — naming where a regime is structurally
insufficient and what additional structure escapes the insufficiency.
The framework's taxonomy is currently asymmetric in a way the names
half-acknowledge:

| Meta-pattern facet | Agent-side | Designer-side |
|---|---|---|
| Constructive-impossibility | `#disc-identifiability-floor` ✓ | *currently nowhere* |
| Coordinate-forcing | `#disc-additive-coordinate-forcing` ✓ | (n/a — different question) |
| Scope (positive) | `#disc-separability-pattern` ✓ | (would inherit from agent-side via sub-scopes) |
| Constructive-impossibility posture | `#disc-constructive-impossibility-posture` ✓ | (currently single-instance; expanded by this landing) |

Landing the designer-side meta-segment completes the missing-but-implied
category. The framework gains structural symmetry without expanding scope.

### 1.c The strengthened-consequence subtlety (epistemic honesty)

For the identifiability-floor, strengthened consequences elevate
specific AAT machinery to load-bearing (loop-interventional access,
observability-as-augmentation, etc.). For the implementation-
impossibility cluster, the strengthened consequence is structurally
different but *methodologically* the same:

- **Where standard escapes intersect AAT machinery:** Sub-scope $\alpha'$
  of `#deriv-strategic-composition` (potential / monotone games) is, in
  mechanism-design terms, a *preference-domain restriction* — one of
  GS's and Arrow's standard escape routes. The meta-segment can name
  this intersection precisely.
- **Where standard escapes lie *outside* AAT machinery:** Bayes-Nash IC,
  randomization, monetary subsidies, bargaining mechanisms. The
  meta-segment honestly documents these as escapes-from-the-
  impossibility that are *not* currently AAT machinery, *mapping the
  framework's outer boundary in the mechanism-design direction*. This is
  itself an epistemic-honesty contribution: AAT names where its
  machinery ends rather than overclaiming or silently overlooking.

The meta-segment's strengthened consequence is therefore the
*precision of the boundary* — what AAT machinery contributes to which
escape routes, and where the framework's contribution stops. That
precision is the contribution; it is not a weaker contribution than the
floor's machinery-elevation. It is the same kind of contribution at a
different layer.

## 3. Meta-segment design

### 3.a Charter scope (the discipline filter)

The new meta-segment covers **constructive-impossibility-shaped
designer-side theorems only**. The filter is the same five-step shape
the floor uses:

1. **Setting** — a mechanism-design or social-choice task under a
   specified constraint regime (which agents, which preferences, which
   information, which incentive condition).
2. **External theorem** — an established mechanism-design or
   social-choice impossibility theorem (GS, M-S, Arrow, etc.) whose
   statement and truth are independent of AAT.
3. **No-go** — the external theorem forbids the design task under the
   specified constraints.
4. **Boundary characterization** — the conditions under which the
   regime fails (i.e., the designer has *more* freedom than the regime
   allows) admit implementation; these boundary routes are the
   well-known escapes from the mechanism-design literature, **with
   explicit annotation of which intersect AAT machinery and which do
   not**.
5. **Strengthened consequence** — *for this cluster*: the precision of
   the AAT/mechanism-design boundary in the constructive-impossibility
   direction. Where escapes intersect AAT machinery (e.g., preference-
   domain restriction ↔ sub-scope $\alpha'$ potential games), that
   intersection is named. Where they don't (Bayes-Nash IC, randomization,
   subsidies), that's documented as honest scope-mark.

**Out of scope for the meta-segment** (the filter does the work):
- Constructive mechanism-design results (revenue equivalence, VCG, etc.)
  — these are *results*, not *constructive impossibilities*.
- Auction theory in general — too broad; the filter only admits
  impossibility-shaped theorems.
- Social-choice theory in general — same reason.

The meta-segment's discipline is *narrow by design*; that narrowness is
load-bearing for epistemic honesty.

### 3.b The actor-and-remedy contrast with the identifiability-floor

The meta-segment must make this distinction sharp from the start
(probably in its opening paragraphs or in a dedicated §"Relationship to
Identifiability Floor"):

| | Identifiability Floor | Implementation Impossibility |
|---|---|---|
| **Actor under the no-go** | An *agent* (in-scope per `#scope-agent-identity`) inferring from data | A *designer* implementing a mechanism under incentive constraints |
| **Information regime** | What the agent observes / can infer | What the designer can implement / commit to |
| **Kind of remedy** | Augment the agent's data / sensing / interventional access | Relax the design constraints / extend the strategy space / introduce transfers |
| **AAT-machinery role in escapes** | Often the *unique broadly-available* escape (loop-interventional, observability-as-augmentation) | Mostly *adjacent* to AAT — intersects sub-scope $\alpha'$ of strategic composition; many escapes are mechanism-design-native |
| **Strengthened consequence** | Elevates specific AAT machinery to load-bearing | Maps the AAT/mechanism-design boundary precisely |

Both are instances of the constructive-impossibility-posture
(`#disc-constructive-impossibility-posture`); both are boundary-face
facets of the stability-certificate spine (`#disc-stability-certificate`).
Sister meta-patterns, not subsumed.

### 3.d Honest scope on what mechanism-design landings look like

Each charter instance (GS, M-S, Arrow) needs its own supporting segment
carrying the formal statement and the AAT-side translation work. Pattern
matches `#disc-identifiability-floor`'s Instance 1 / 2 / 3 / 4 having
home segments. The supporting segments do *not* re-prove the imported
theorems (GS, M-S, Arrow are classical) — they *translate* the theorem
into AAT vocabulary, name which AAT objects play which mechanism-design
roles, and characterize the escapes in AAT's regime/sub-scope language
where applicable.

Tier honesty in supporting segments:
- The imported impossibility theorem itself: *exact* (classical).
- The translation into AAT vocabulary: *derived* (mechanical, but
  requires identifying the right AAT-side object — designer / mechanism
  / strategy space / outcome rule).
- The intersection with AAT sub-scope $\alpha'$ where applicable:
  *derived conditional* (depends on the preference-domain mapping).
- Claims about AAT machinery providing escapes: *carefully scope-marked*
  — most escapes don't intersect, and the honest statement is that the
  framework documents the boundary without claiming to provide most
  escapes.

## 4. Charter instances (drafted; executor refines)

### 4.a Gibbard-Satterthwaite (GS, 1973–75)

**Setting.** A social choice rule $f: L^n \to A$ aggregating $n$ agents'
strict preferences over $\ge 3$ alternatives into a single outcome
under the dominant-strategy incentive compatibility (DSIC) constraint
and the requirement that $f$ be non-dictatorial and surjective onto $A$.

**External theorem.** Gibbard (1973), Satterthwaite (1975): no such $f$
exists. Equivalently: every DSIC, non-dictatorial, surjective social
choice rule on unrestricted preferences over $\ge 3$ alternatives is
manipulable.

**No-go.** A designer who insists on DSIC + non-dictatorial + surjective +
unrestricted preferences cannot construct the rule.

**Boundary characterization (the escapes).**
- **Preference-domain restriction** (e.g., single-peaked preferences —
  Black 1948; admits the median-voter rule). **Intersects AAT
  machinery:** maps roughly to sub-scope $\alpha'$ of
  `#deriv-strategic-composition` — potential-game / monotone-game
  preference structures.
- **Weakened solution concept** (Bayes-Nash IC instead of DSIC, e.g.,
  d'Aspremont-Gérard-Varet mechanisms). **Outside AAT machinery.**
- **Randomization** (e.g., Gibbard 1977 random dictator). **Outside AAT
  machinery.**
- **Restricted strategy space** (limit agents to truthful reporting via
  enforcement). **Outside AAT machinery.**

**Strengthened consequence.** The boundary between AAT and mechanism
design is precisely characterized here: sub-scope $\alpha'$ of
`#deriv-strategic-composition` corresponds to one of GS's standard
escape routes (preference-domain restriction), making the AAT/mechanism-
design intersection structurally explicit; the other escapes belong to
the mechanism-design literature, *not* to AAT. Documenting this
precisely is the contribution.

**Tier.** *Exact* (classical). *Derived conditional* for the AAT
translation. *Robust qualitative* for the AAT/mechanism-design boundary
characterization.

### 4.b Myerson-Satterthwaite (M-S, 1983)

**Setting.** Two-party bilateral trade under private information about
valuations, with the designer seeking a mechanism that is
simultaneously: ex-post efficient (always trade when buyer's value
exceeds seller's), Bayesian incentive compatible (BIC), individually
rational (IR — voluntary participation), and budget-balanced (no
subsidies).

**External theorem.** Myerson & Satterthwaite (1983): no such mechanism
exists.

**No-go.** A designer demanding ex-post efficiency + BIC + IR +
budget-balance cannot construct the bilateral-trade mechanism.

**Boundary characterization (the escapes).**
- **Subsidies** (relax budget-balance — e.g., VCG with deficit).
  **Outside AAT machinery.**
- **Second-best mechanisms** (Myerson 1981 optimal trade with
  inefficient withholding). **Outside AAT machinery.**
- **Common values** (relax private values — Lehrer-Hellman, etc.).
  **Outside AAT machinery, but adjacent** to the regime-indexed
  identification structure (`#scope-edge-update-causal-validity`).
- **Long-run reputation / repeated interaction** (single-shot M-S
  doesn't bind in indefinitely-repeated games — Folk-theorem-style
  escapes). **Outside AAT machinery; adjacent** to the strategic-
  composition machinery in repeated-game form.

**Strengthened consequence.** The M-S boundary is almost entirely
outside AAT's current machinery — honest scope-mark. The bilateral-trade
designer's problem is *adjacent* to AAT (the two-agent strategic-
composition machinery applies to the agents' best-response dynamics
*given* a mechanism, but the *choice of mechanism* is the designer's
problem and lives outside AAT). This honest delineation is the contribution.

**Tier.** *Exact* (classical). *Derived conditional* for the AAT
translation (clean for the agents-given-mechanism layer; carefully
scope-marked for the designer's mechanism-choice layer).

### 4.c Arrow (1951)

**Setting.** A social welfare function $F: L^n \to L$ aggregating $n$
agents' strict preference orderings into a single social preference
ordering over $\ge 3$ alternatives, under: Unrestricted domain (U) +
Pareto efficiency (P) + Independence of Irrelevant Alternatives (IIA) +
Non-dictatorial (ND).

**External theorem.** Arrow (1951, 1963): no such $F$ exists.

**No-go.** A designer demanding U + P + IIA + ND cannot construct the
social welfare function.

**Boundary characterization (the escapes).**
- **Preference-domain restriction** (e.g., single-peaked, single-crossing
  — admits Condorcet-consistent rules). **Intersects AAT machinery**
  via the same sub-scope $\alpha'$ correspondence as GS.
- **Weakened IIA** (e.g., positional methods — Borda count, range
  voting). **Outside AAT machinery.**
- **Supermajority requirements** (e.g., 2/3 thresholds). **Outside AAT
  machinery.**
- **Cardinal preferences** (relax the ordinal-only restriction —
  utilitarianism, range voting). **Outside AAT machinery; adjacent** to
  `#form-objective-functional`'s value-functional machinery (which
  carries cardinal value content).

**Strengthened consequence.** Arrow shares GS's preference-domain
escape intersection with sub-scope $\alpha'$, and adds an interesting
*adjacent* connection through the cardinal-preference escape and AAT's
value-functional machinery. Both connections are *adjacent* (not
elevation of AAT machinery to load-bearing); the honest scope-mark
documents this clearly.

**Tier.** *Exact* (classical). *Derived conditional* for the AAT
translation.

### 4.d On the Roberts theorem and the Vickrey-Clarke-Groves bound

These were considered as potential additional charter instances but are
deliberately *not* included at landing:
- **Roberts (1979) "Affine maximizers theorem"** (only weighted-utility-
  sum mechanisms are DSIC on unrestricted preferences with monetary
  transfers): a borderline candidate; the discipline filter admits it,
  but landing it at the same time as GS/M-S/Arrow risks scope-creep.
  Flag as a candidate for a future landing if the meta-segment matures.
- **VCG / revenue-equivalence** (Myerson 1981 — what is achievable
  with monetary transfers): *constructive* result, not an impossibility-
  with-escape; deliberately *excluded* by the discipline filter.

The meta-segment's narrowness is load-bearing. Three charter instances
at landing; additional candidates land later only if they pass the
filter.
