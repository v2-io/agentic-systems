# spikes/.routing-trail/ — the spike-routing process trail

The durable archaeology of the spike-routing process: per-cycle
**adjudication** (`SPIKE-WORKING-<id>/`), **independent-verify**
(`SPIKE-VERIFY-<id>/`), and **regression-recheck**
(`SPIKE-REGRESSION-<id>/`) reasoning trails. The six-digit ID is
identity; the prefix is the class — never blanket-rewrite one prefix to
another (directory-prefix invariant, inherited from
`audits/README.md`).

Live cycle state is **[`../ROUTING.md`](../ROUTING.md)**; the governing
process is **[`../../doc/spike-routing.md`](../../doc/spike-routing.md)**;
the per-cycle move record is
**[`../.integrated/MANIFEST-2026-05-17.md`](../.integrated/MANIFEST-2026-05-17.md)**.
The load-bearing *conclusions* of every trail here are extracted into
those durable layers + `CHANGELOG.md` + the committed canon
edits/marks — what lives here is the *reasoning detail behind* them.
These are **frozen reasoning trails**: preserved as-written, not
rewritten (rewriting first-encounter cognition is the failure the
archival discipline forbids), the same stance `audits/README.md` takes
toward its working dirs.

> [!note]

> produced when the live tracker was `msc/spike-routing-2026-05-17.md`
> and these dirs were `audits/SPIKE-{WORKING,VERIFY,REGRESSION}-<id>/`.

> for the cycle's durable rendezvous) and `audits/` is the *audit*

> directive): the tracker → `spikes/ROUTING.md` (de-dated — the routing
> *process* is ongoing, not a one-shot 2026-05-17 artifact); these dirs →
> here. Where a trail document internally writes
> `msc/spike-routing-2026-05-17.md` or `audits/SPIKE-…`, read it as
> `spikes/ROUTING.md` / `spikes/.routing-trail/SPIKE-…` — the documents
> are frozen as-written and deliberately not back-edited; this note is
> the rosetta, exactly as `audits/README.md` handles the AAD→AAT rename.

Lifecycle: per `doc/spike-routing.md`, a trail dir is retained here as
archaeology once its conclusions are in the durable layer; it is not
deleted (the project preserves reasoning trails) and not summarized into
oblivion. This tree is intentionally dot-prefixed so `ls spikes/` stays
scannable.
