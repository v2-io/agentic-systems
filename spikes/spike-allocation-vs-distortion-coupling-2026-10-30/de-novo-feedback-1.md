## 1. L0 should not land as written; the finding underneath it is real and different

**What the plan says.** `proposed-integration-plan.md` L0: canon's CI form $M_{\tau^+} \perp G_t \mid (M_{\tau^-}, e_\tau)$ at `der-directed-separation.md:204` "is false as written for exactly the agents `:16`/`:56` permit; the repair is $M_{\tau^+} \perp G_t \mid (M_{\tau^-}, a_t, e_\tau)$ … This is a one-token change with a derivation behind it and should land first."

**Canon's CI is true as written.** For an agent whose update is $M_{\tau^+} = f_M(M_{\tau^-}, e_\tau)$ (with any internal randomness independent of $G_t$), $M_{\tau^+}$ is a function of the conditioning variables, so $M_{\tau^+} \perp G_t \mid (M_{\tau^-}, e_\tau)$ holds whatever colliders sit upstream of $e_\tau$. The collider of §1.1 opens a path between $G$ and $\Omega$, not between $G$ and $M^+$. So the CI is not false. What §1.1 shows is that a different statement fails: the posterior that conditions on $e$ without $a$ is not the Bayes posterior given everything the agent did.

**The repair is vacuous in the generic goal-directed case.** If the policy $a = \pi(M, G)$ is injective in $G$ at fixed $M$, then $G$ is a function of $(M^-, a)$, and $M^+ \perp G \mid (M^-, a, e)$ holds for every update, including a fully distorting one. If the policy is many-to-one, the repaired CI still passes any distortion that depends on $G$ only through the action taken. The same substitution in $\kappa_{\text{processing}}$ makes its denominator $H(G \mid M^-, a, e) = 0$, so the 0/0 problem canon's audit gold already flags at `:237` would become generic.

**V7, the finding underneath.** $\Omega \in \{0,1\}$ uniform; $G \in \{0,1\}$ with $P(G=0) = 0.8$, independent of $\Omega$; the policy is $a = G$; the event is $e = \Omega \oplus a$. Take a goal-blind agent in canon's form, $f_M(M^-, e)$ with no $a$, reporting the pooled posterior $P(\Omega = 1 \mid e)$, which is $0.2$ at $e = 0$ and $0.8$ at $e = 1$. Its $\kappa_{\text{processing}}$ is $0$, since $M^+$ is a function of $e$. Pooled over goals it is calibrated (reliability $0$ under the log score). Under each goal's own law it is not: per-goal reliability is $0.2231$ nats under $G = 0$ and $1.6094$ nats under $G = 1$. That is a goal-blind agent with large reliability loss that varies with the goal.

**Consequence for §9.** §9 says *"The architectural classification by $\kappa_{\text{processing}}$ certifies, at $\kappa = 0$, that no goal-attributable reliability loss is possible"*, and `proposed-integration-plan.md` §3 relies on it. V7 refutes that under canon's own update form. Under goal-directed selection where the event depends on the action, an update without a goal port and without the realized action is miscalibrated per goal. The certificate needs an added hypothesis: the update receives the realized action and uses it only through the action-indexed likelihood $P(e \mid \Omega, a)$. That is what Kalman + LQR does with its control input, so the canonical Class 1 example passes.

**What I would land instead.** Change the update form to $f_M(M^-, a, e)$ (an efference copy), together with the norm that $a$ enters only through the likelihood. Stated as a criterion: $M^+$ is calibrated given $(M^-, a, e)$ under each goal's law. Neither an observational CI nor an argument-list check carries this. The CI with $a$ is vacuous. The argument list with $a$ is leaky, because $f_M(M^-, a, e)$ can decode $G$ from $a$ and distort, and the interventional reading "invariant under $\mathrm{do}(G)$ holding $(M^-, a, e)$ fixed" passes that agent too. The spike's own criterion (Definition 2.1, Lemma 2.2) is the only one of these that separates the agents correctly. This strengthens the spike's central move rather than softening it: the realized action is the place where selection and processing meet, and only calibration draws the line there. The B.1 record for directed separation should carry this as the condition under which Class 1's certificate holds.

## 2. The law under which calibration is evaluated has to be the per-goal law, and Definition 2.3 does not say so

Definition 2.3 defines the family "at fixed $(M^-, a, e)$" and calls it allocation if "every member is calibrated." At fixed $(M^-, a, e)$ each member is one distribution. Definition 2.1 is a property of a random belief, and under the law conditioned on $(M^-, a, e)$, $\sigma(M^+_G)$ is trivial, so calibration there means $M^+_G = P(\Omega \mid M^-, a, e) = \pi$. Read literally, then, the allocation class is empty under (NWI): an agent that encodes $x_1$ but not $x_2$ is not calibrated at a fixed event that includes $x_2$. The intended object is clearly the map $e \mapsto M^+_G(e)$, calibrated over the law of $(\Omega, e)$ given $G$; that is what (N3) computes. The repair is to say so, and to say which law. V7 shows the choice is not cosmetic: pooled over goals the goal-blind agent has reliability $0$, and under each goal's own law it has reliability $0.22$ and $1.61$. Theorem 3.1's $\mathrm{REL}(G)$ needs the same specification. Calibration under each goal's law implies pooled calibration ($P(\Omega \mid m) = \sum_G P(G \mid m)\, m = m$), but the converse fails, so a pooled diagnostic can miss a defect.

## 3. Paper 3's Class 1 does not say "the goal may enter only as evidence"; the reading is inverted

§5.3: *"Paper 3's Class 1 is defined as '$G \perp M^+ \mid \Omega$ given $(e, M^-)$' … which read literally is *the goal may enter beliefs only as evidence about the world*. That is the correct normative criterion."* §8 repeats this ("read as a norm, exactly right").

**V4.** Take the goal-as-evidence Bayesian of (N7$\beta$): $G$ is uniform; $P(\text{flaw} \mid e, G) = 0.8$ or $0.2$; the agent reports $M^+ = P(\Omega \mid e, G)$. Then $I(G; M^+ \mid \Omega, e) = H(G \mid \Omega, e) = 0.5004$ nats, which is greater than $0$. So the literal CI excludes exactly the agent the spike says it permits. The reason is general. An agent with no access to $\Omega$ beyond $e$ cannot route goal-dependence "through $\Omega$". If its internal randomness is independent of $\Omega$ given its inputs, then $G \perp M^+ \mid (\Omega, e, M^-)$ reduces to "the law of $M^+$ given $(e, M^-, G)$ does not depend on $G$", which is plain goal-blindness. The data-processing step in Paper 3 is then unnecessary, because the numerator of $\kappa$ is already zero.

**The other direction.** Paper 3's $\kappa$ for the same agent is $I(G; M^+ \mid e) / I(G; \Omega \mid e) = \log 2 / 0.1927 \approx 3.60 \gt 1$. So the correct goal-as-evidence Bayesian also violates $(H_\kappa)$ at $\kappa^\ast = 1$. §5.3's sentence *"the paper's architectural corollary describes agents that use the goal as evidence, not agents that distort"* is wrong in that direction as well. Under $(H_\kappa)$ with $\kappa^\ast = 1$, the corollary covers agents that transfer no more goal-information than the goal's evidential value. The evidential Bayesian transfers all of $H(G)$ and is out.

Calibration (Definition 2.1) is the norm the spike reaches, and it is the right one. The two sentences crediting Paper 3 with it should be deleted, not softened. Nothing else in §5.3 depends on them.

## 4. Two "iff" statements labeled exact are "if" statements

**Proposition A′** (F, exact): *"Allocation preserves calibration iff the encoding mechanism is ignorable with respect to the dropped content, or the updater models the mechanism."* **V6:** take (N3)'s world and add a third feature $x_3$ independent of $\Omega$. Always encode $x_1$; encode $x_3$ only when $x_3 = 1$, dropping it on its value. Use the naive update. The mechanism is non-ignorable in Rubin's sense, and the reported belief $P(\Omega \mid x_1)$ is calibrated (reliability $0$). Rubin's condition is sufficient. The "only if" needs a clause such as "and the dropped content is informative about $\Omega$ given what is retained", and even with that clause, coincidental calibration under a non-ignorable rule is not excluded without a genericity argument. I would state A′ as sufficiency, add the informativeness remark, and drop "iff". (`lit-scan.md` §6.1 rates Rubin 1976 and Heitjan–Rubin 1991 at abstract level only, so "it is Rubin 1976 applied to the agent's own attention" also deserves a primary read before it lands.)

**Break-point 4.** The README says 5a is starved *"exactly when the allocator's decision set lacks the objective-revision option"*, the §12 table says *"starvation iff the allocator's decision set lacks the revise option"*, and L3 proposes *"a capacity-limited allocator that values information only over goal-pursuing actions never gathers feasibility evidence."* This is false in both directions. (N10) is the spike's own counterexample to one direction: the revise option is present but never optimal, and VOI is $0$. **V5** breaks the other. Keep (N6)'s world ($P(f_1 = 1) = 0.5$, $P(\text{feasible}) = 0.6$) with a pursue-only decision set, but let one pursuing action carry a cost paid regardless: $a_1$ pays $1$ if feasible and $f_1 = 0$; $a_2$ pays $2$ if feasible and $f_1 = 1$, minus $0.4$ always. Then $\mathrm{VOI}(f_{\text{feas}}) = 0.06$ (at $P(\text{feasible}) = 0.9$ it is $0.04$). Proposition 7.1 itself survives, because its hypothesis requires every pursuing action to pay the same under infeasibility, and V5 violates that hypothesis. The table row, the README sentence, and L3 dropped the hypothesis. The exact statement is the standard one: feasibility evidence has positive VOI iff learning it changes the optimal action with positive probability and a gain. Starvation is the case where every action the allocator can choose ties under infeasibility. Lacking a revise option is one way that happens, and having a revise option is not enough to prevent it.

Proposition 7.1(a) is stronger than its proof makes it look. The VOI of $f_{\text{feas}}$ is zero even when feasibility is correlated with the other payoff-relevant features. Under the tie hypothesis, $\mathbb E[U(d) \mid \mathcal H] = P(\text{feas} \mid \mathcal H)\, \mathbb E[v_d \mid \text{feas}, \mathcal H] + c_0 (1 - P(\text{feas} \mid \mathcal H))$, and the argmax is the argmax given feasibility with or without observing it. The proof's "linear in $P(\text{feasible})$" is right, but read naively it suggests that independence is needed, and it is not. Separately, (a)'s "never encodes it" holds only when capacity binds and positive-VOI alternatives exist; at zero VOI the allocator is indifferent.

## 5. The replacement law (§6): the identity is universal, so its content is the factorization, and the factorization has the same identifiability problem as $\kappa \cdot \mathcal A$

The §6 scope paragraph: *"This is a theorem within a model class (multiplicative reweighting of a calibrated base) … Additive-content-form distortions (a goal-dependent shift of a mean that is not a reweighting) are not covered."* Any belief $M^+$ mutually absolutely continuous with $\pi$ is a multiplicative reweighting, with $r_G := dM^+/d\pi$. The identity $\mathrm{KL}(\pi \Vert M^+) = \log \mathbb E_\pi r - \mathbb E_\pi \log r$ therefore holds for every distortion except out-of-support mass (instance 11). With $r$ normalized it reduces to $-\mathbb E_\pi \log r$. (N12) already shows that a Gaussian mean shift is a tilt. So the exclusion is mistaken and the "model class" is not a restriction. The identity is a tautology, and the content of Theorem 6.1 is entirely in the parameterization $\log r_G = \lambda u_G + \text{const}$.

That has two consequences for L2, which proposes landing this law "as the carrier of the same engineering intuition".

- Given only $M^+$ and $\pi$, the pair $(\lambda, u_G)$ is identified only up to $\lambda u_G$. The split into a processor gain and an observation-times-goal spread is meaningful only if $u_G$ is fixed independently, for example as the goal's utility over world states. That is a substantive D-claim: the distortion points in the utility direction, which is wishful thinking. Fear-driven pessimism, plan-consistency pressure, and sycophancy toward an interlocutor's goal need not point there. Without that commitment the law has the same disease the spike diagnoses in $\kappa \cdot \mathcal A$: a product whose factors are not separately well-posed.
- The base $\pi = P(\Omega \mid \mathcal H)$ is the calibrated posterior given the agent's own allocated information. That is how the law is "zero for allocation-only agents by construction". It also means the left side is not observable without knowing $\mathcal H_G$, and Remark 3.4's indistinguishability applies to the replacement as much as to the original. §6's *"computed from the goal-blind posterior and the goal's desirability function, with no agent in it"* is not accurate, because $\pi$ depends on the agent's allocation. If $\pi$ is instead the full-information goal-blind posterior, allocation shows up as displacement, which is what the law was meant to avoid.

None of this touches the identity, the two Hoeffding bounds, or (iii). I checked the reverse direction the spike asked a verifier to write out. With $X = \log r_G \in [a, a + L]$ on $\mathrm{supp}\,\pi$ and $Z = \mathbb E_\pi e^X$: $\mathbb E_{M^+} e^{-X} = \mathbb E_\pi[e^X e^{-X}]/Z = 1/Z$. Hoeffding's lemma under $M^+$ for $-X$ gives $-\log Z \le -\mathbb E_{M^+} X + L^2/8$, that is $\mathrm{KL}(M^+ \Vert \pi) = \mathbb E_{M^+} X - \log Z \le L^2/8$. Pinsker then gives $\mathrm{TV} \le L/4$. That is correct, and it uses that $\mathrm{supp}\, M^+ = \mathrm{supp}\,\pi$.

My suggestion for L2 is to land the identity in its universal form, with $r = dM^+/d\pi$ and range $L$ of the log density ratio, as the exact model-free statement that "sharp observations leave no room" — the item §13's first bullet calls unattempted. This answers that item, at least for the support-preserving case. Land the exponential parameterization separately as a D-hypothesis with the regression test §13 names.

## 7. "Goal-variation of reliability isolates distortion" fails under misspecification and under an unconditioned action

§2.4: *"only the goal-variation of reliability at fixed evidence isolates the former"* (goal-attributable distortion). This is carried into L8 and the cross-cutting E.1 suggestion. Two points.

- "At fixed evidence" does not parse for reliability, which is an expectation over events. I take the intended meaning to be across goals, over the same event law.
- **V1.** Take (N3)'s world under the true law ($P(\Omega = 1) = 0.6$, feature accuracies $0.9$ and $0.6$) and an agent with the correct prior that believes both accuracies are $0.75$. It allocates $x_1$ under $g_1$ and $x_2$ under $g_2$ and updates by Bayes under its own model, so there is no distortion. Under the world's law its reliability is $0.0706$ under $g_1$ and $0.0523$ under $g_2$. Goal-varying reliability, pure allocation. V7 gives a second, larger case from the action channel. Under the world's law, goal-variation of $\mathrm{REL}$ separates distortion from allocation only for a well-specified agent that conditions on its own action. E.1 should carry the per-goal reliability term and say that it cannot by itself attribute distortion on an LLM, which is the agent most likely to be misspecified.

## 8. Remark 3.4 is too strong: some distortions are refutable without outcomes

Remark 3.4 says that from goal-probing data alone the two kinds are indistinguishable, and that Theorem 3.1 "needs either outcomes … or an oracle posterior". Without outcomes there is still a Reflection, or Bayes-plausibility, screen: the average reported posterior over the event law should equal the prior. **V3:** in (N3)'s world the two allocators average $0.6000$, equal to the prior, and the flagship tilt ($\lambda = 1$ on the full posterior) averages $0.6851$. The scan's label-swap example (H6) shows the screen is necessary and not sufficient. Dorst's ambiguity (instance 16) and misspecification can both trip it on an honest agent, so it refutes only under the same two hypotheses as §7. The accurate form: outcomes are needed to *certify* allocation; a martingale screen without outcomes can *refute* a class of distortions under well-specification and access. That matters for E.1's cost, and the scan already lists the Martingale Score (He et al. 2025) as an instrument.

## 9. §9's norm should name goal-chosen ignorance, which is calibrated and is not a capacity trade-off

§9: *"Goal-dependence of the information itself … is not a defect … and is a resolution trade-off, not a reliability loss."* §2.6 earns "trade-off" at fixed capacity. **V2:** prior $P(\text{feasible}) = 0.3$. The agent picks its own information structure to maximize the probability of a belief of at least $0.5$, Kamenica–Gentzkow style. When feasible it always sees signal $s$; when infeasible it sees $s$ with probability $3/7$. Then $P(s) = 0.6$, the posterior after $s$ is exactly $0.5$, and the posterior after the other signal is $0$. Reliability is $0$. Resolution is $0.195$ nats against $0.611$ for full information. The probability of holding the favorable belief doubles, from $0.3$ to $0.6$. No capacity limit is involved: the resolution was given up in order to shape the belief, not traded for anything. `lit-scan.md` H7 and §2.6 (Golman et al., Caplin–Leahy, Bénabou–Tirole) already surface this, but the derivation's norm does not absorb it. The spike's split still holds: this is not a calibration defect. The norm sentence should still name a third case beside allocation and distortion — calibrated but strategically uninformed, an allocator whose objective is the belief rather than the decision. Good's theorem marks it as decision-dominated for a conditionalizer whose utility does not depend on its own credences. It is the sibling of §7's starvation: §7 is an allocator pricing out an option, V2 is an allocator pricing in a belief. For a theory about agents that persist by tracking reality, this is the case the degradation norm "less coupling tracks reality strictly better" was arguably about.

## 10. §11's wrapper reading misplaces the sycophancy mechanism

§11: *"under (C2′)+(C3), goal-dependent query selection with a calibration-preserving update — allocation, with zero reliability cost. What does cost reliability … is a (C3) failure (the component infers the operator goal from the query and tilts its answer)."* As formalized at `der-class-coercion-via-wrapping.md:55`–`:75`, (C3) is $P(A(q_M) \mid q_M, G_W) = P(A(q_M) \mid q_M)$. A component that reads goal cues in $q_M$ and tilts its answer is a fixed function of $q_M$, so it satisfies (C3) and (C2′). The segment itself puts this mechanism in the selection channel: *"the latent operator goal $G^{\text{op}}$ … which a competent component can infer from the content of the query"* (`:93`). So $\kappa_{W_1}^{\text{sel}} = I(A(q_M); G^{\text{op}})$ mixes the wrapper's query choice (allocation) with cue-triggered miscalibration by the component (distortion). L6's "the only change is the word 'leakage'" understates it. The spike's own framework names the condition the wrapping theorem is missing: $A(q)$ calibrated given $q$, an honest answerer, which neither (C2′) nor (C3) delivers. This connects to the open Working Note at `der-directed-separation.md:215`, where the "inference effect" is the distortion half.

## 11. §5.1 survives and can be made stronger, but it owes canon a fairer framing

Canon's own `:30`(ii) already states that $\mathcal A \to 0$ when "the goal tells you nothing about the world that the observation didn't already determine". So the zero is not hidden. It is a mismatch between canon's definition and canon's gloss at `:31`: *"Different plausible goals map the same observation to systematically different world-states"* describes goal-relative *relevance* of residual uncertainty, which is roughly what §6's $\mathrm{sd}_\pi(u_G)$ measures, and not goal *informativeness*. Framing it this way changes how L2 reads ("the definition did not express the intended quantity", not "the factor is identically zero").

A strengthening the spike did not make: canon presents $P_{\text{ref}}(G)$ as a *convention* "without tying it to the processing architecture" (`:28`), analogous to `#def-value-object`'s reference policy. For $I(G; \Omega \mid e, M^-)$ to be positive under a reference prior, the reference law has to couple goals to world states, and canon never specifies such a coupling. Under the natural reading, with $G$ drawn by convention independently of the world, $\mathcal A \equiv 0$ for every event, not only under (NWI). Also, the converse half of §5.1 ("positive exactly when using the goal is correct Bayesian updating") is computed in (N7$\beta$) without actions. With the realized action in the conditioning set, as §1.1 requires, and an injective policy, $I(G; \Omega \mid e, a, M^-) = 0$ even for an informative goal, because the action already reveals it. The dichotomy should be stated in the setting where it holds: the interventional probe, with $G$ varied at a fixed event and the reference law naming how goals carry world information.

## 12. The spike places attention on both sides, as canon does

§4: *"Attention is selection applied to the agent's internal channel … the first two are one phenomenon at two boundaries."* §6 puts "precision weighting, attention gain" in the multiplicative process-form cell, which is distortion. Calibration does resolve this: hard, ignorable selection of what is encoded is allocation, and soft reweighting of likelihood contributions (tempering) is distortion. The §4 sentence and "one phenomenon at two boundaries" should carry that restriction. There is also a real asymmetry between the two boundaries that the "one phenomenon" sentence hides. External selection is decided before the content arrives. Internal attention in a transformer is computed from the content it weighs, so under Proposition A′ it is generically non-ignorable, as `lit-scan.md` §5 already reasons. For Class 3 internals the clean allocation cell may be close to empty, and the cases where allocation is clean are mostly at the external query level. L5's new typology cell should say this, or someone will read the result as "LLM goal-directed attention is benign".
