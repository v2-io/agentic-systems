# Derived: Orient Cascade

For actuated agents, epistrophe (the corrective phase of the cycle) expands from a single step into a *multi-step cascade*. The order of its first three steps — epistemic update, then attainability assessment, then strategy evaluation — is *not a design choice* but a consequence of which quantities require which others: each step's input is the output of the step before. That objective revision comes last is a rule of a different kind. Nothing in the information flow prevents an agent from revising its objective as soon as the satisfaction gap is computed; the steps that precede revision are what produce the evidence that distinguishes an infeasible goal from a wrong model, a narrow policy class or a short horizon, so an agent that revises earlier acts on an undiagnosed gap. The ordering is forced where it is a dependency and recommended where it is a diagnosis; the Epistemic Status and the Claim Record say which is which.

The five steps. (1) **Reduce epistemic mismatch** — update $M_t$ via #def-mismatch-signal and #emp-update-gain. Prerequisite for all purposeful evaluation, because $M_t$ appears in every subsequent formula. (2) **Evaluate the satisfaction gap** ( #def-satisfaction-gap) — is the goal achievable? Requires an adequate model to assess attainability. (3) **Evaluate the control regret** ( #def-control-regret) — is the policy suboptimal? Applied regardless of the satisfaction gap's sign because the 2×2 diagnostic requires both quantities to distinguish four cases (success / strategy problem / capability limit / both). (4) **If regret is high, evaluate strategy calibration** — three sub-steps: 4a plan-level calibration via the strategy-plan-confidence error $\delta_s$ (credit-assignment-free, persistence proved within L0); 4b per-edge localization via the strategic-calibration residual ( #def-strategic-calibration) when sufficient observability and attribution are available; 4c *causal-sufficiency check* — if 4a has converged but plan-outcome residuals remain persistently negative, the DAG is causally insufficient and L0 is converging to a biased target; the diagnostic is pairwise sibling covariance under exploration ( #der-causal-insufficiency-detection), and the remedy is L1 augmentation by adding common-cause nodes ( #def-strategy-dag Correlation Hierarchy) *before* escalating further. (5) **If the satisfaction gap persists** — escalate before revising the objective: 5a check whether model correction changes feasibility; 5b check whether a richer policy class (including L1 augmentation if 4c signaled it) would close the gap; 5c check whether convention escalation (C1 → C2 → C3 per #def-value-object) reveals recovery paths; only then 5d revise the objective. The cascade ensures *objective revision is the last resort, not the first response to unmet goals* — the agent reaches 5d only after exhausting the alternatives the satisfaction-gap disambiguation table identifies (wrong model, narrow policy class, short horizon, then genuinely infeasible goal). When 5d is performed by a principal, the revised objective is externally sourced (a standard actuated agent); when *internalized* it becomes the self-actuation operator, well-formed only under a grounding condition (a non-degenerate self-actuator must ground objective-revision on a non-objective terminal invariant, not on an objective-functional).

The *inferential force* at each step scales with the value-object continuation convention while the *ordering* itself is convention-independent (the dependency part because it is a fact about which quantities use which, the recommended part because nothing in it names a convention). Under C1 (one-step improvement, canonical default), a positive satisfaction gap means *locally stuck*, not *globally infeasible* — a multi-step recoverable objective may appear unattainable because continuation is frozen at the current policy. Under C2 (receding-horizon), the diagnostics capture multi-step recovery potential. Under C3 (Bellman), the gap is definitively global. The cascade also surfaces a *virtuous/vicious cycle* between model quality and strategy complexity: better model → richer evaluable strategy → better-directed action → faster model improvement; and inversely, degraded model → forced strategy simplification → cruder action → further model degradation. The latter is the strategic analog of the persistence-condition death spiral ( #result-persistence-condition). A related complexity bound surfaces in Discussion: the strategy's evaluable complexity is bounded by the model's capacity — an agent with poor model sufficiency cannot meaningfully evaluate a complex strategy because calibration residuals require adequate model to distinguish "edge prediction wrong" from "observation too noisy to tell." The cascade is the formal analog of Boyd's *Orient*: not just model updating, but the structured interaction between reality-understanding and strategy that Boyd identified as the critical step (not Decide). The cascade provides a mathematical mechanism — Orient resolves the information dependencies that make Decide meaningful; an agent that skips to Decide without adequate Orient will revise its strategy based on stale or incorrect beliefs.

## Formal Expression

*[Derived (orient-cascade, from information dependency between mismatch types)]*

1. **Reduce $\delta_{\text{epistemic}}$** — understand reality.  
   Update $M_t$ via #def-mismatch-signal and #emp-update-gain. Prerequisite for all purposeful evaluation, because $M_t$ appears in every subsequent formula.

2. **Evaluate $\delta_{\text{sat}}$** — is the goal achievable?  
   Compute $A_O(M_t; \Pi, N_h)$ using the updated $M_t$. Requires adequate $M_t$ to assess attainability ( #def-satisfaction-gap).

3. **Evaluate $\delta_{\text{regret}}$** — is the policy suboptimal?  
   Compare $A_O$ to $V_O(M_t, \pi_{\text{current}}; N_h)$ ( #def-control-regret). This step applies regardless of $\delta_{\text{sat}}$'s sign — the 2×2 diagnostic ( #def-control-regret) requires both quantities to distinguish four cases:
   - $\delta_{\text{sat}} \leq 0$, $\delta_{\text{regret}} \approx 0$: **success** — goal attainable, policy near-optimal.
   - $\delta_{\text{sat}} \leq 0$, $\delta_{\text{regret}} \gg 0$: **strategy problem** — goal attainable, policy poor → revise $\Sigma_t$.
   - $\delta_{\text{sat}} \gt 0$, $\delta_{\text{regret}} \gg 0$: **both** — goal hard AND strategy weak → revise $\Sigma_t$ first (cheaper than revising $O_t$), then reassess $\delta_{\text{sat}}$.
   - $\delta_{\text{sat}} \gt 0$, $\delta_{\text{regret}} \approx 0$: **capability limit** — already doing the best available; proceed to step 5.

4. **If $\delta_{\text{regret}}$ high, evaluate strategy calibration** — is the plan's causal model wrong?

   **(4a) Plan-level calibration (default within-L0).** Evaluate strategy-plan-confidence error $\delta_s = \hat P_\Sigma - \Phi$ — the gap between the agent's strategy-plan-confidence score and the independence-model plan value at true edge parameters. $\delta_s$ is credit-assignment-free (requires only status propagation), and its persistence is proved ( #schema-strategy-persistence, Prop B.5 in #deriv-edge-credence-dynamics). This is the cheapest operational signal, but its persistence guarantee is within the **independence model (L0)** of the Correlation Hierarchy ( #def-strategy-dag): $\delta_s \to 0$ means $\hat P_\Sigma$ has converged to $\Phi$, not to actual plan success probability. When the DAG is causally insufficient, $\Phi$ itself is a biased target. Step 4c checks whether this is the binding regime.

   **(4b) Edge-level localization (when credit assignment is available).** When sufficient observability and attribution quality exist (Level 1+ per #disc-credit-assignment-boundary), the agent can compute per-edge residuals $\delta_{\text{strategic}}$ ( #def-strategic-calibration) to localize which edges need revision. $\delta_{\text{strategic}}$ provides finer-grained diagnostics but its persistence is open and it requires the credit-assignment machinery that $\delta_s$ avoids. Step 4b is optional — it improves diagnostic resolution but is not required for the cascade's corrective function.

   **(4c) Causal-sufficiency check (L0→L1 escalation).** If persistent $\delta_s \approx 0$ coincides with persistent plan-outcome residuals ($y_G \neq \hat P_\Sigma$ on average, after edge credences have converged; usually $y_G \lt \hat P_\Sigma$, from a shared enabling cause at OR-dominated roots), this is evidence that the DAG is causally insufficient and L0 calibration is converging to a biased target. The trigger has a precondition that #der-causal-insufficiency-detection makes exact: under on-policy short-circuit execution the plan-level residual is *identically zero* once edge credences have converged to the regime conditionals, so the residual can fire only when the credences were learned from uncensored outcomes — which is exactly when the covariance test below is already available. The diagnostic is pairwise sibling covariance under an augmented test ( #der-causal-insufficiency-detection): nonzero covariance among sibling edges, at timescales where each edge's individual credence has stabilized, localizes where a latent common cause is missing. Its sign says whether the cause enables siblings together or makes them exclusive. When the signal for L1 augmentation is present, step 4c directs the agent to add common-cause nodes ( #def-strategy-dag Correlation Hierarchy) *before* escalating via 5a–5d. Running the cascade's exploitation recommendations under L0 when the signal for L1 is present compounds miscalibration — the agent acts confidently on a model whose own residual structure is telling it the model is wrong.

   *Practical sensitivity.* Step 4c is the unique broadly-available L0→L1 diagnostic ( #der-causal-insufficiency-detection no-go), but its effective power depends on signal-to-noise: small samples, weak common-cause effects, or noisy residuals can produce false negatives, and edge-credence drift can mimic sibling covariance. The convergence framing — "after edge credences have converged" — is a precondition, not a guarantee: in non-stationary environments where per-edge credences keep drifting, the trigger may never cleanly fire and L1 augmentation should be considered the default rather than gated on 4c's signal ( #def-strategy-dag Correlation Hierarchy). Formal preconditions (joint observability, per-edge credence stabilization, approximate stationarity over the test window) and detection scope live in #der-causal-insufficiency-detection; consult them before treating a 4c null as evidence of L0 sufficiency.

5. **If $\delta_{\text{sat}} \gt 0$ persists** — escalate before revising $O_t$.

   **Under C1 (the canonical default), $\delta_{\text{sat}} \gt 0$ means *locally stuck*, not *globally infeasible*** ( #def-value-object). Before concluding the objective is wrong, the agent should check whether the gap reflects a limitation of the current analysis rather than genuine infeasibility:

   **(5a)** Check whether $M_t$ correction changes the feasibility assessment — a wrong model may make an achievable goal appear unattainable. This step presupposes that the model carries the evidence that bears on feasibility, and an agent whose encoding is allocated by the value of its decisions need not have gathered it. For an allocator that chooses what to encode, at fixed capacity, to maximize the expected value of the best decision in a set $D$, a feature whose only effect on payoffs is to make *every* action in $D$ pay the same when the goal is infeasible has value of information exactly zero — learning it never changes the argmax — so a capacity-limited allocator never spends on it and 5a has nothing to work with (exact, in two lines: with $p(X) = P(\text{feasible} \mid X)$, $\max_a \mathbb E[u_a \mid X] = p(X) \max_a v_a(X) + (1 - p(X))\, c(X)$, which equals the expectation over feasibility of $\max_a \mathbb E[u_a \mid X, F]$, so the value of learning $F$ is zero). The hypothesis is the tie: an abandon-or-revise action whose payoff does not depend on feasibility breaks it *when that action is optimal under infeasibility and not under feasibility* (its presence alone does not — an option never optimal adds no value), and a pursuing action with a cost paid regardless of feasibility breaks it on the same condition, when the cost makes a different action optimal under infeasibility than under feasibility (a cost on the action that is not best under feasibility leaves the tie broken and the value still zero). In general feasibility evidence has positive value iff learning it changes the optimal action with positive probability. So the starvation is not a property of goal-directed allocation; it is a property of pricing the information over a decision set in which infeasibility makes no difference — which is the cascade's own structure seen from the attention side, since 5a–5c precede 5d and an allocator that values only pursuing actions has already priced 5d at zero. Three remedies, as design claims with the named test (agents with and without each, in worlds where the goal becomes infeasible through a goal-irrelevant feature): a goal-independent encoding reserve; objective revision inside the allocator's decision set, which needs a value for "goal revised" not computed from the goal's own functional ( #deriv-self-actuation-grounding); or an observer whose attention this agent's goal does not shape ( #hyp-solicitable-escape).

   **(5b)** Check whether a richer policy class $\Pi$ would close the gap — structural $\Sigma_t$ adaptation (expanding the strategy space, not just revising edge credences). This includes L1 augmentation of the strategy DAG ( #def-strategy-dag Correlation Hierarchy): if step 4c detected causal insufficiency, adding common-cause nodes here is the structural repair.

   **(5c)** Check whether convention escalation reveals recovery paths — evaluating under C2 (receding-horizon) may show $\delta_{\text{sat}}^{\text{RH}} \leq 0$ for a goal that appeared unattainable under C1. The C2 recovery-path reading presumes the replanning objective is order-consistent (window-covering, value-compared, or terminal-cost guarded per #def-value-object); unguarded short-horizon replanning is not guaranteed to dominate the frozen baseline.

   **(5d)** If $\delta_{\text{sat}} \gt 0$ persists across $M_t$ correction, $\Pi$ expansion (including L1 augmentation), and convention escalation — **revise $O_t$**.

   The cascade's ordering ensures objective revision is the last resort, not the first response to unmet goals. The agent reaches step 5d only after exhausting the alternatives that the satisfaction-gap disambiguation table ( #def-satisfaction-gap) identifies: wrong $M_t$, narrow $\Pi$, short $N_h$, and only then genuinely infeasible goal. When step 5d is performed by a principal the revised $O_t$ is externally sourced (an actuated agent); when it is *internalized* — performed by the agent on itself — it becomes the self-actuation operator, which — as a conditional, scoped no-go ( #deriv-self-actuation-grounding) — is well-formed only under a grounding condition: a non-degenerate self-actuator must ground objective-revision on a non-objective terminal invariant, not on an objective-functional.

**Derivation.** Two kinds of ordering are in the list, and they have different warrants.

*Forced by information dependency* (each step's input is a prior step's output):
- Step 2 computes $A_O(M_t; \Pi, N_h)$, a function of $M_t$, so it follows step 1; a strategy cannot be evaluated against a reality model that has not been updated.
- Step 3 computes $\delta_{\text{regret}} = A_O - V_O(\pi_{\text{current}})$, a function of step 2's $A_O$, so it follows step 2; "locally bad strategy" and "locally unattainable goal" are distinguished only when both quantities are in hand.
- Step 4c's test is defined on stabilized edge credences ( #der-causal-insufficiency-detection, preconditions), so it follows 4a's convergence; before that, sibling covariance is not separable from ordinary calibration error.

*Recommended, on diagnostic and cost grounds* (nothing in the information flow prevents the other order):
- Step 4a before 4b: the per-edge residual $\delta_{\text{strategic}}$ is computable without $\delta_s$; running the cheap plan-level signal first avoids paying for credit assignment when the plan is calibrated.
- Step 5's substeps before 5d: $\delta_{\text{sat}}$ is already in hand at step 2, and the agent could revise $O_t$ there. The checks 5a–5c are what produce the evidence that separates the rows of the disambiguation table ( #def-satisfaction-gap): a gap that survives $M_t$ correction, $\Pi$ expansion (including L1 augmentation when 4c signals it) and convention escalation is evidence of infeasibility, and a gap that does not is not. The rule is to act on a diagnosed gap, and to prefer the cheaper revision ($\Sigma_t$ before $O_t$). It has no stopping rule of its own, so it does not say how long to persist (Claim Record).

The split of step 4 into 4a/4b/4c reflects three distinct diagnostic levels: 4a gives a within-L0 persistence signal (plan-level tracking via $\delta_s$), 4b gives within-L0 edge-level localization when credit assignment is available (Level 1+), and 4c exits L0 entirely when the independence model is the binding constraint. L1 augmentation ( #def-strategy-dag Correlation Hierarchy) enters 5b as a structural $\Sigma_t$ adaptation when 4c's signal is present.

**Convention hierarchy and diagnostic power.** The 2×2 diagnostic and the inferences drawn from it are relative to the continuation convention in the value object ( #def-value-object), which defines a hierarchy of three conventions with a proved monotonicity result.

Under **C1** (one-step improvement, canonical default), $\delta_{\text{sat}}$ and $\delta_{\text{regret}}$ are one-step-improvement quantities. A multi-step recoverable objective may appear locally unattainable ($\delta_{\text{sat}} \gt 0$) because continuation is frozen at $\pi_{\text{current}}$. The "capability limit" quadrant ($\delta_{\text{sat}} \gt 0$, $\delta_{\text{regret}} \approx 0$) means *locally stuck* — the agent may be globally recoverable but cannot see the recovery path from one-step analysis.

Under **C2** (receding-horizon, $N_r$-step replanning), the diagnostics capture multi-step recovery potential. An objective that appeared unattainable under C1 may show $\delta_{\text{sat}}^{\text{RH}} \leq 0$ because replanning reveals a viable path. The "capability limit" quadrant means *stuck with $N_r$-step replanning* — stronger evidence of genuine difficulty.

Under **C3** (Bellman), the diagnostics are global. $\delta_{\text{sat}}^{\text{B}} \gt 0$ means the goal is genuinely infeasible given $(M_t, \Pi, N_h)$ — no policy can achieve it. The "capability limit" quadrant is a definitive diagnosis: the agent is optimally pursuing an infeasible goal (modulo model error in $M_t$). This is the inference the cascade was designed to support; C1 and C2 provide progressively weaker versions of it.

The monotonicity ( #def-value-object): $\delta_{\text{sat}}^{\text{B}} \leq \delta_{\text{sat}}^{\text{RH}} \leq \delta_{\text{sat}}^{(1)}$. Every "unattainable" diagnosis under C3 persists under C1 and C2. A C1 "unattainable" diagnosis may be overturned by C2 or C3 (the goal is reachable with replanning or globally optimal play). The cascade's ordering is convention-independent: its first three steps are forced by information dependency, and objective revision last is a recommendation (Epistemic Status), under every convention alike. The *inferential force* at each step scales with the convention: C1 gives local heuristics, C2 gives moderate-horizon diagnostics, C3 gives global conclusions.

## Epistemic Status

The ordering of steps 1–3, and the precondition that 4c waits on 4a's convergence, are *exact*: logical consequences of which quantities appear in which formulas. The rule that objective revision comes last (5a–5c before 5d) and the order 4a before 4b are not dependencies: $\delta_{\text{sat}}$ is computed at step 2, and $\delta_{\text{strategic}}$ needs no $\delta_s$. They are *normative*, grounded in the disambiguation table of #def-satisfaction-gap (the checks produce the evidence that separates its rows) and in the relative cost of revising $\Sigma_t$ and $O_t$; they are tested by comparison against agents that order the steps otherwise, and no such comparison has been run (Claim Record). Steps 1-2 (epistemic update, attainability assessment) rest on well-typed quantities ( #def-mismatch-signal, #def-satisfaction-gap) and exact derivation. Step 3 (control regret) is exact ( #def-control-regret). Step 4a (plan-level calibration via $\delta_s$) is grounded in a proved quantity — the sector condition transfers to $\delta_s$ (Prop B.5 in #deriv-edge-credence-dynamics) — but the formal guarantee is *within the L0 independence model*: $\delta_s \to 0$ means convergence to $\Phi$, which equals actual plan success, for all credences, exactly when the DAG is a causally sufficient AND/OR tree ( #deriv-graph-structure). Step 4b (per-edge localization via $\delta_{\text{strategic}}$) inherits strategic-calibration's discussion-grade status — the credit-assignment problem and execution-fidelity requirement are acknowledged but unresolved ( #def-strategic-calibration, Epistemic Status). Step 4c (causal-sufficiency check) is the mechanism for exiting L0 when L1 is the binding regime; it is *robust-qualitative* — the diagnostic logic is sound ( #der-causal-insufficiency-detection), but sensitivity depends on how cleanly the agent can separate sibling-covariance signal from edge-credence noise at convergence. Step 5's escalation substeps (5a-5c) are the checks that produce the evidence separating the rows of the satisfaction-gap disambiguation table ( #def-satisfaction-gap); that they run before 5d is the recommendation stated at the top of this section, not a derivation. What is NOT derived is the *timing* — how long the agent should spend on each step before proceeding, and how long $\delta_s \approx 0$ must persist before 4c's signal is trusted.

The **convention hierarchy** ( #def-value-object) is *exact*: the three conventions (C1, C2, C3) are definitions, and the monotonicity result is a direct consequence of "better continuation policy yields higher expected value." The diagnostic implications table states what each convention's quantities mean by construction. The cascade's inferential force at steps 2-5 scales with the convention but the ordering is convention-independent.

## Claim Record

### Beliefs are resolved before anything that reads beliefs, and attainability before regret

**Register:** formal — a dependency among the formalism's own quantities (Formal Expression, "Forced by information dependency"): $A_O$ is a function of $M_t$, $\delta_{\text{regret}}$ is a function of $A_O$, and 4c's test is defined on converged credences. Exact. Directed separation is what lets step 1 complete before step 2 begins; without it the three are a joint fixed point.

**Population:** representations of agents in learning-agent scope ( #der-causal-hierarchy-requirement) running at $\kappa_{\text{processing}} = 0$ ( #der-directed-separation, causal discipline). At $\kappa_{\text{processing}} \gt 0$ the sequential order approximates a simultaneous resolution; how far the approximation is off is the agent's distortion, and how far its readings vary with the goal is bounded by the displacement bound of #deriv-observation-ambiguity-bias-bound — $\kappa$ itself does not index the degradation, since it saturates at any noiseless coupling.

**True of:** the 3-arm bandit of #example-strategy, which walks the steps in order (internal consistency, not instantiation).

**False of:** a Class 3 component in a single goal-conditioned call: the goal is upstream of every computation, so there is no goal-blind step 1 to run first; the order can be imposed on its output and recovered at the wrapper under strict wrapping ( #impl-orient-cascade, §"Coupled architecture"). A joint solver that resolves $M_t$, $\Sigma_t$ and $O_t$ together is not excluded by the dependency: it evaluates nothing on a stale input, it solves the fixed point.

**Falsifier:** none at the level of agents; a demonstration that $\delta_{\text{regret}}$ can be evaluated without $A_O$ would contradict its definition.

**Instantiated:** not applicable.

### Revise the objective last

**Register:** normative — the rule that 5a–5c precede 5d, and that 4a precede 4b (Formal Expression, "Recommended"). Nothing in the information flow forbids revising $O_t$ once $\delta_{\text{sat}}$ is computed at step 2; the rule says to act on a diagnosed gap and to prefer the cheaper revision. It is a design claim: an agent that orders its revisions this way does better than one that does not.

**Population:** learning-agent-scope agents with a satisfaction threshold $V_{O_t}^{\min}$ and a channel for objective revision, whether internal (self-actuation, #deriv-self-actuation-grounding) or through a principal acting on the agent's report. The body names military doctrine (Boyd's Orient) and, by a fresh reader's mapping, software debugging and clinical diagnosis as practices of this shape ( #def-control-regret, Working Notes).

**True of:** no measured instance. The practices named are instances of the rule's shape, not tests of it.

**False of:** the body's own aspiration hypothesis ( #def-satisfaction-gap, tag `aspiration-dominance`) says that keeping an infeasible objective is sometimes optimal by a feasible objective's measure, in which case "revise once the gap survives every check" is wrong for that agent. The rule has no stopping rule, so it does not separate persistence that pays from escalation of commitment (Staw 1976, cited at #der-belief-strategy-attractor) and does not say when the early revision it discourages is the right one.

**Falsifier:** in environments with a known mix of feasible and infeasible goals and a known drift rate, agents that run 5a–5c before 5d earn no more value and waste no less effort than agents that revise the objective first, or than joint planners. The comparison between bold and cautious intention reconsideration in Tileworld (Kinny & Georgeff 1991[^recall-2026-10-30]), where the better policy depended on the world's rate of change, is the existing test of this kind; it has not been run on the cascade.

**Instantiated:** no.

### The cascade is what Boyd's Orient does

**Register:** descriptive, offered as a conjecture (Discussion, "Connection to Boyd's OODA"): the body claims the cascade is the formal analog of Orient and says whether it captures the cognitive process Boyd described is an empirical question.

**Population:** human decision-makers running an observe–orient–decide–act loop; by extension, scaffolded LLM agents with reflect-then-replan loops ( #impl-orient-cascade).

**True of:** no checked instance.

**False of:** none known; no instance has been checked.

**Falsifier:** a record of the order in which practitioners revise belief, plan and goal when a plan fails. The body specifies no protocol; one would have to be written before the claim can be tested.

**Instantiated:** no.

## Discussion

**$G_t$ complexity bounded by $M_t$ capacity.** $\Sigma_t$'s evaluable complexity is bounded by $M_t$'s ability to observe which strategy edges are intact. An agent with poor model sufficiency ($S(M_t) \ll 1$) cannot meaningfully evaluate a complex $\Sigma_t$ — the strategic calibration residual requires adequate $M_t$ to distinguish "edge prediction wrong" from "observation too noisy to tell."

This creates a **virtuous cycle**: better $M_t$ → richer evaluable $\Sigma_t$ → better-directed action → faster $M_t$ improvement. And a **vicious one**: degraded $M_t$ → forced strategy simplification → cruder action → further $M_t$ degradation. The vicious cycle is the strategic analog of the death spiral described in the persistence condition ( #result-persistence-condition) — the agent loses the capacity to maintain complex plans, which reduces the quality of its actions, which further degrades its model.

**Connection to Boyd's OODA.** The orient cascade is the formal analog of Boyd's "Orient" — not just model updating, but the structured interaction between reality-understanding and strategy. Boyd's insight was that Orient is the critical step, not Decide. The cascade provides a mathematical mechanism consistent with this insight: Orient resolves the information dependencies that make Decide meaningful. An agent that skips to Decide (strategy revision) without adequate Orient (model update + attainability assessment) will revise its strategy based on stale or incorrect beliefs. Whether the dependency structure in the cascade captures the actual cognitive process Boyd described is an empirical question.

**Timescale structure.** The cascade implies a natural timescale ordering for the different update types:

$$\nu_{\text{epistemic}} \gg \nu_{\text{edge-update}} \gg \nu_{\gamma\text{-reclassify}} \gg \nu_{\text{prune/graft}} \gg \nu_{O\text{-revision}}$$

Weight updates are frequent (every observation). Combination-type reclassification is rare (needs strong structural evidence). Pruning/grafting is rarer still (abandon or create causal hypotheses). Objective revision is rarest (change what you want, not how you get it). This ordering is an empirical observation for many agent populations, consistent with the cascade but not derived from it.

## Working Notes

- **Reproduction.** The step-5a value-of-information enumerations (the tie, the abandon action, the cost on either action) are registered as `empirica:part-ii-coupling-checks`.
- The cascade as stated is sequential. In practice, agents may run steps in partial overlap — beginning to assess $\delta_{\text{sat}}$ before $M_t$ is fully updated, or revising edges while still processing observations. The cascade describes the *logical* dependency, not the *temporal* scheduling. An agent that parallelizes steps must still respect the dependencies (don't finalize strategy revision using a stale $M_t$).
- The resource allocation question (how much of the agent's tempo budget to spend on each step) is open and may be domain-dependent. In fast-changing environments, the agent may need to truncate early steps to keep up. In stable environments, the agent can spend more time on deep strategic evaluation.
- The virtuous/vicious cycle between $M_t$ quality and $\Sigma_t$ evaluable complexity is structurally motivated but not formally derived. Formalizing it would require a coupled dynamics model — possibly an extension of the persistence framework to the $(M_t, \Sigma_t)$ pair.
- **Strategy-maintenance status (updated).** The cascade's ordering is exact where it is a dependency (steps 1–3; 4c after 4a's convergence) and a recommendation where it is not (objective revision last; 4a before 4b). The cascade's CONTENT for steps 3-5 has progressed: #disc-credit-assignment-boundary characterizes the tractable/intractable boundary and establishes that persistence does not require credit assignment (Prop B.5); #deriv-edge-credence-dynamics verifies sector conditions for four topologies; #hyp-edge-update-via-gain has a default signal function candidate (gradient-based, satisfying directional fidelity). What remains domain-specific: the choice of signal function implementation, execution-fidelity monitoring, and handling of correlated failures (where $\hat P_\Sigma$ overestimates — #def-strategy-dag). The theory now provides the structural requirements and a default scheme; specific implementations are engineering, parallel to how the gain principle provides $\eta^\ast$ while Kalman/TD-learning/etc. are implementations.

#### 1. Candidate Brief prose / pre-prose

#### 2. Candidate Discussion

- **The cascade is an instance of itself (the audit as worked example)** *(strongest framing here).* An auditor noticed the audit it was conducting *is* the cascade: each segment read updates $M_t$ (model of the framework); periodic strategic-loop revision is the $\Sigma_t$ revision; the audit objective $O_t$ ("produce a defensible audit") is held constant — "the cascade's 'objective revision is the last resort' parallels my own audit discipline: I haven't changed my audit objective even when I found that the framework is more sophisticated than I predicted" (Claude, AUDIT-WORKING-451729, batch-13). A self-exemplifying analogy that the segment could carry as a reader-facing illustration of the forced ordering.
- **The timescale hierarchy as a model of psychological stability and trauma.** The empirical timescale ordering ($\nu_{\text{epistemic}} \gg \nu_{\text{edge-update}} \gg \nu_{\gamma\text{-reclassify}} \gg \nu_{\text{prune/graft}} \gg \nu_{O\text{-revision}}$) reads as "a beautiful description of human maturation and psychological stability": a healthy mind updates facts constantly, tweaks habits daily, rarely abandons a career, almost never changes core identity/values. Under trauma the hierarchy *inverts* — frozen $M_t$ (refusing to update facts) while wildly swinging life goals (rapid $O_t$ revision) "in a desperate attempt to escape the pain of the satisfaction gap" (Gemini, AUDIT-WORKING-193847). A vivid Discussion angle on the timescale-ordering Working Note. *(Note the early-conflation texture: evocative analogy, not derived — verify isomorphism before promoting past discussion-grade.)*
- **The vicious cycle as a formalization of cognitive decline / organizational collapse.** Three substrates independently read the $M_t$/$\Sigma_t$ vicious cycle as a precise model of decline: degraded $M_t$ $\to$ noise drowns the credit-assignment signal $\to$ agent forced to prune the strategy DAG to simple reactive policies $\to$ simple policies generate poorer interventional data (lower CIY) $\to$ further $M_t$ degradation. "This is a mathematical formalization of cognitive decline or organizational collapse" (Gemini, AUDIT-WORKING-773921; converging at Gemini, AUDIT-WORKING-193847 — "if your sensors are noisy, you literally cannot execute a complex plan because you can't tell which step failed", echoed at Gemini, AUDIT-WORKING-849201). A candidate sharpening of the existing vicious-cycle paragraph.
- **The cascade as a formal refutation of goal-first / action-first architectures.** "It provides a formal refutation of 'Goal-first' or 'Action-first' architectures" — most current LLM agent frameworks (ReAct, AutoGPT, LangChain) use a crude undifferentiated "Thought" step, and the cascade proves epistemic update *must* precede the rest (Gemini, AUDIT-WORKING-193847; Gemini, AUDIT-WORKING-829314). The framework's load-bearing position against alternative cascade orderings is already named in `#impl-orient-cascade`; this is a Discussion-grade restatement of *why* with concrete contrast cases.

"This provides a principled way to manage the massive inference cost (token budget) of running LLM agents — you only pay for deep Chain-of-Thought deliberation when the cascade mathematically demands it" (Gemini, AUDIT-WORKING-829314). A candidate implementation note bridging to `03-llm-core/`.

#### 4. Readers often ask / wonder

- **What distinguishes the "ordering exact" claim from the step-content status?** Multiple fresh readers landed on the same precise split and found it clean — "the ordering is exact as a dependency graph; timing, thresholds, and step-4 diagnostics remain conditional or discussion-grade" (Codex/Claude, AUDIT-WORKING-526815; the same clean split praised at Claude, AUDIT-WORKING-266847 — "the logical structure is exact; the specific content of each step is harder"). Readers want the exact/non-exact boundary made unmissable, since "ordering exact" can be misread as "the whole cascade is exact."

A candidate one-line orientation before the convention-hierarchy block.

#### Off-ramp (NOT gold) — routed for adjudication

These surfaced in the same sweep but are certified-track (structure/computability), not pedagogical gold. Recorded here so they are not lost; they need the strengthen-first / consolidated-queue routing, not promotion into Brief/Discussion.

- **Step 4a/4c trigger: proof-target vs. computable proxy.** Step 4a uses $\delta_s = \hat P_\Sigma - \Phi$ as the default operational signal, but $\Phi$ is the independence-model plan value *at true edge parameters*, which the agent does not directly possess. Likewise step 4c's trigger depends on "persistent $\delta_s \approx 0$." If $\delta_s$ is proof-level rather than computable, both triggers need an observable substitute (stabilized edge credences + residual statistics) (F83/F84 candidates, Codex/Claude AUDIT-WORKING-526815). Distinguishing the proof target from the empirical convergence proxy is a structural clarification, not a wording fix.
