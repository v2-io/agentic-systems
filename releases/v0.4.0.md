## What this release is

v0.1.0 was the first public deposit of the whole *Agentic Systems Framework* — four components, no assembled reading artifact. This release is centered on the **first assembled monograph volume**: **AAT Volume 1**, the mathematical core, built end-to-end from the claim segments by the markdown-first pipeline and shipped as both a PDF (1,111 pages, scrbook, LuaTeX) and the canonical assembled markdown it was typeset from. Both are attached to this release and also live at the repository root as `CURRENT-VOL1.pdf` / `CURRENT-VOL1.md` (byte-identical to `mono/aat-v0.4.0s.pdf` / `mono/aat-v0.4.0.md`).

The version number is the AAT *volume's* version (`01-aat-core/mono-meta.yaml`), which has been advancing internally — v0.2.0 (2026-05-22) and v0.3.0 (2026-06-05) builds exist in `mono/` but were never released. This release adopts the volume version as the repository tag going forward, so there is no v0.2.0 / v0.3.0 GitHub release; the framework-level history from v0.1.0 to here is summarized below.

The volume's own opening states what it is (from the assembled Introduction):

> We assert that an agent — a system that maintains an internal picture of an external world it can only ever see in part, acts on that world, and must continually adapt to external realities — is not an open-ended mystery to be approached only by analogy and benchmark. It is a temporal feedback system characterized by a small number of critical quantities and constraints. […] These bounds describe not only how a system behaves while its conditions hold, but — sharply, and as an exact dichotomy in the stochastic case — what happens when they fail.

Four results anchor the volume, in its own words: a **Persistence Threshold** (one inequality — correction rate against drift, relative to how wrong the agent can afford to be — governing a Kalman filter, a software team, and an organization as one result rather than an analogy among three); a **Containment Dichotomy** (bounded disturbance is held forever with certainty; genuinely stochastic disturbance is left, with probability one, over an unbounded horizon — so changing *what kind of model it is* is a certain eventual event for any long-lived agent); a **Stability Equivalence** (the organizing principle is identically the classical Lyapunov stability theorem); and an **Architectural Classification** (whether beliefs can be updated without contamination from what the agent wants holds by construction for some architectures, fails by construction for others — transformer language models among them — with a constructive route to recover it at quantified cost).

## What has changed since v0.1.0

653 commits; 309 files changed under the four component trees (+42,602 / −3,686 lines). The full narrative is in [`CHANGELOG.md`](https://github.com/v2-io/agentic-systems/blob/main/CHANGELOG.md) (2026-05-02 → 2026-07-29; commits after that date — a research seed on AGI definitional well-posedness, working notes gathered for AISI, plans for the adaptive-reserve clarification, and this release's build — are in git only and not yet narrated there). The landings that most change what a reader meets:

**The name.** Adaptation and Actuation *Dynamics* (AAD) became Adaptation and Actuation *Theory* (AAT) on 2026-05-15, and component directories harmonized to `01-aat-core` / `02-tst-core` / `03-llm-core` / `04-eli-core`. The v0.1.0 notes' paths (`01-aad-core/`, `03-logogenic-agents/`, `04-eli/`) are historical.

**Volume / Part / Chapter structure and the monograph pipeline** (2026-05-11 → 05-12, refined through 05-25). The OUTLINE files went hierarchical; a three-stage ingest → assemble → typeset pipeline (`bin/build-monograph`) produces per-volume PDFs and assembled markdown. The four meta-pattern segments were relocated out of the appendices to the Part openings they precede (*introduced before used*), and the introduction, scope-cascade figure, and recurring snow-driver worked instance were written for the assembled volume.

**Meta-architecture completed: M4.** Alongside M1 identifiability-floor, M2 separability, and M3 additive-coordinate-forcing (present in v0.1.0), **M4 modularity-state dynamics** landed 2026-05-24 — three structurally distinct operations (truthification, strategic self-coupling, adversarial coupling pressure) acting on the GUC Class 1/2/3 architectural state, with their pairwise dualities. The Class 2 (partial-coupling) sub-typology landed 2026-05-22; directed separation was re-founded on the *causal discipline* noun and object-and-boundary view 2026-05-31; the operator-family unification and stability-certificate spine landed 2026-05-14.

**Goal-Update Coupling class renumbering** (2026-05-09; git tag `pre-guc-rename-2026-05-09` marks the boundary). v0.1.0's "Class 1 / 2 / 3 = modular / fully merged / partial" is now **GUC Class 1 Separated / Class 2 Partial / Class 3 Coupled** — the old Class 2 and 3 swapped. Any v0.1.0 text naming LLMs "Class 2" now reads Class 3.

**Strengthen-first repairs from de-novo audits, several past the original claim.** The Model-S non-exit strengthening (2026-05-16); the $\rho$-decomposition truthification, in which a false segment was rebuilt true (05-18); the matrix-Loewner persistence condition (succeed-beyond-claim, 05-12); the multi-timescale stability promotion sketch → *exact* for Model D under named premises (06-10); the three-term mismatch decomposition with the $\rho_\star$ boundary regression corrected (07-03); the tempo-additivity spike, which **refuted and replaced** an asserted redundancy inequality with an echo-chamber bound plus two no-gos, and its ripple audit across the tempo cluster (07-15 → 07-16). Two coefficient corrections are worth naming plainly because v0.1.0 stated the wrong ones: the Landauer thermodynamic floor is $\tfrac{1}{2}\,n\alpha\,k_BT$ per unit time (not $\approx 0.35$; a bit/nat mix), and the gain–sector bridge now states per-event and per-time forms explicitly rather than "$\alpha = \mathcal T$ exactly."

**Causal access re-grounded.** Forkability is not a Pearl-level demotion; the sandbox evaluation ceiling is a *transportability* result (2026-05-30, read against Bareinboim et al. directly), promoted to its own segment; the agency scope's contrast channel made explicit (05-29); the anti-collapse discipline named and given a canonical home (05-29). **Level-4 strictness**: mechanism counterfactuals separate strictly from Pearl Level 3 via a two-line boolean witness (`#deriv-mechanism-counterfactual-separation`, *exact*, 2026-07-16), with a professional literature search returning no prior statement; agentic consequences landed as `#disc-law-discovery-ceiling` and `#obs-authored-world-laboratory`. The three escapes from an absorbing observability region were shown not to be peers (`#hyp-solicitable-escape`, 2026-07-29).

**Value and objective grounding.** Revealed preference grounded on named representation axioms; convention-monotonicity shown one-sided with $Q_O$ causal validity gated; the continuity stance split into three grains (all 2026-05-31); the implementation-impossibility and value-functional-grounding-floor meta-segments (05-22).

**Part 04 (ELI) — the deaths taxonomy restructured.** `#hyp-the-three-deaths` became `#def-death-as-factor-loss` (2026-06-10): a death is the loss of a constitutive factor, giving *four* deaths — continuity, relational, truth, agency — with a fifth (phenomenological) predicted and deliberately unadjudicated. Agency death was grounded as severed-actuation dynamics with a two-terminal structure including extreme volitional abdication as the most permanent form (06-11 → 06-12); mood as second-order adaptation and agency death's input leg (06-17). **The name "Three Deaths" used in v0.1.0 is retired**; nothing was ever published claiming three.

**Process, hygiene, and integration debt paid.** The 64-spike bulk integration of 2026-05-12 was verified spike-by-spike (54 landed / 6 partial / 3 superseded / 1 nothing-to-land; 5 unlanded claims refuted; 21 confirmed-unlanded items then landed, 07-16); canon now cites only other canon and the published external world (§G2, 05-30); the `empirica/` experiment registry was founded with the Part I nonlinear simulation corpus; terminology infrastructure (`bin/term`, per-entry store, `LEXICON.md` generated) went live (176 term entries, `LEXICON.md` generated from them); SOPs consolidated under `doc/sop/`; ~103 done items pruned from forward trackers.

## Known limitations of the release artifacts — read before citing a page

Two independent peer reviews of the exact PDF and markdown attached here were run on 2026-08-15 with no shared notes ([`msc/aat-v0.4.0-pdf-review.md`](https://github.com/v2-io/agentic-systems/blob/main/msc/aat-v0.4.0-pdf-review.md), [`msc/aat-v0.4.0-assembled-md-review.md`](https://github.com/v2-io/agentic-systems/blob/main/msc/aat-v0.4.0-assembled-md-review.md)). Both conclude the build is a real volume — no segment dropped, no theory invented, chapter order intact — and both conclude it is **a review-variant working snapshot, not yet a clean stranger-facing publication artifact**. The theory is the release; the typesetting is a snapshot of a pipeline mid-build. Specifically:

- **Review variant.** The build is the `:review` variant: **164 segment Working Notes sections** (audit gold, candidate briefs, open questions) ride in the body under a lighter face; ~244 of 1,111 pages mention them. They are process residue, skippable once recognized, and honest — but a stranger will experience the volume as a monograph interleaved with a development diary. A `--public` build strips them.
- **Title-page stamp.** The reviewed build read `119d049-dirty`; the attached PDF was rebuilt after the cause (an untracked build log written before compile) was gitignored and reads `v0.4.0 • 185a615 • 2026-08-15`. PDF metadata (Title/Author/Subject) is still empty.
- **Five chapters open with the literal marker `[Gap] Discussion`** (Chapters 9, 10, 13, 14, 16) where the chapter-intro segment is not yet written. Four further gaps are listed honestly in Chapter 16's Working Notes.
- **Appendix BD is a stub** for the unwritten `#worked-example-cam` (Miller 2022 / Moore machines / $\varepsilon^\ast = 0$) and appears in the ToC under its raw slug.
- **Raw `#slug` cross-references survive** in a systematic class of places (equation-tag brackets, some figure captions and one appendix title) instead of resolving to `\cref` numbers; the markdown additionally carries 15 repo-relative `.md` links and 5 absolute image paths that do not resolve outside the checkout. Cross-volume citations (`03-llm-core`, `04-eli-core`) are correctly *not* rewritten and remain unresolved in-volume.
- **The bibliography is 10 entries and reads as complete; it is not.** Only `\cite`-keyed references were ingested. Miehling et al. 2025 (named in the Introduction), Miller 2022, Nesterov, van der Schaft & Schumacher, Rockafellar / Bauschke–Combettes, Hafez et al. 2026, and others cited in body text or footnotes are absent from the back page. Treat it as a partial pipeline sample.
- **Three dependency-graph SVGs named in the OUTLINE are not in the volume**; three outline-level framing passages (the Part III preface, both appendix-group preambles, Part I's introduction title) were dropped by an ingest buffering defect the review located.
- Two display equations (pp. ~250 and ~493) and the Appendix AN running head overflow the margin; a handful of ToC rows have mechanical defects.

None of these changes what the theory claims. All of them are on the page. The corresponding repairs are pipeline work already itemized in the two reviews; a subsequent build under a patch version will carry them.
