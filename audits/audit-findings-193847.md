### Theme F1 — Boundary-integrity and observation-loss as scope conditions (deeper than the tracker mined)

§01 (`def-agent-environment`, §14) names a constraint the framework leaves *unstated*: **"a hidden assumption here is *boundary integrity*. The environment is opaque, but the boundary itself must be impermeable to direct tampering from the outside, or the definition collapses."** This is a structural commitment as load-bearing as the explicit information-loss condition — but it appears nowhere in current `01-aat-core/src/def-agent-environment.md` or `scope-adaptive-system.md`. Gemini also raised a sharp counterfactual: *"what if the state is perfectly accessible but computationally irreducible?… computation bound equate to an information-loss boundary?"* — the segment says *"observations are necessarily lossy"* but doesn't address **computational opacity as a substitute for perceptual opacity**. This matters for software agents (perfect perception, intractable prediction).

§05 (`scope-adaptive-system`, §14) extends this to a profound observation about *whose entropy is being measured*: **"the entropy is calculated over the *true* environment state $\Omega_t$, which the agent does not know. This means the scope condition is evaluated from the 'God's eye view' of the theoretician analyzing the system, not from the agent's internal perspective."** This is a substantive epistemic-architecture observation: the scope condition is *theoretician-evaluated*, not *agent-evaluated*. The gap between the agent's *estimated* entropy and the *true* entropy is where catastrophic failure occurs (Class-2 LLMs with high internal confidence + opaque world = mode for hallucination).

§06 (`scope-agency`, §14) raises a careful technical point: **the proprioception paradox.** If $o_t$ includes $a_{t-1}$ cleanly through $h$, then $P(o \mid do(a)) \neq P(o \mid do(a'))$ trivially via the proprioceptive channel — even if the action has no effect on $\Omega$. The audit infers: *"to make `#scope-agency` non-vacuous, the causal effect must be on $\Omega$, not just on the proprioceptive part of $o$. The notation $P(o \mid do(a))$ might be hiding a subtle requirement that the difference must route *through* $\Omega$."* **This is a real ambiguity in the scope condition's statement.**

**Disposition for Theme F1.** Three distinct architectural-clarity findings, none redundant with the integration-tracker's lifts. **`architectural` → PROPOSALS candidate**: a unified "scope-condition completeness sweep" that explicitly adds (a) boundary integrity, (b) computational opacity as an OR-substitute for perceptual opacity in the scope statement, (c) proprioceptive-routing clarification in `scope-agency`.
