**Convention hierarchy monotonicity derivation — checkable:**
The derivation: "better continuation yields higher expected value" → $A_O^{(1)} \leq A_O^{\text{RH}} \leq A_O^{\text{B}}$.

Key step: $\pi_{\text{RH}} \succeq \pi_{\text{current}}$ at each future step (C2 re-optimizes where C1 holds fixed) → $Q_O(M_t, a; \pi_{\text{RH}}, N_h) \geq Q_O(M_t, a; \pi_{\text{current}}, N_h)$ for any action $a$ → $A_O^{\text{RH}} \geq A_O^{(1)}$. Can be negative: conditional mutual information is not monotone in conditioning set. Adding $\Omega_t$ can either increase or decrease MI. So the proxy can be negative. ✓ The sign-indefiniteness label is correct.

## 8. What am I now curious about?

**The convention hierarchy as an epistemic ladder.** The C1/C2/C3 conventions are an *epistemic ladder* for diagnostic strength: C1 is the most conservative and computationally cheapest; C3 is the most powerful and most expensive. This parallels the epistemic-strength framework (guess → hypothesis → tested → proven) from the audit instructions. The convention hierarchy makes the diagnostic's inferential force explicit and quantifiable — two agents claiming "my system satisfies δ_sat = 0" need to specify which convention to be comparable.

What I find elegant: the convention hierarchy doesn't require the agent to *solve* the Bellman equation (C3) to compute diagnostics. C1 is always available; it just gives weaker guarantees. This makes the framework practically usable even when exact value computation is intractable.

**The "type error" fix in `def-strategy-dimension`:** The segment resolves a type error in earlier formulations: "earlier formulations used $\delta_{\text{goal}} = G_t - M_t$ as a goal mismatch signal. When $\Sigma_t$ is a DAG, this is a type error — you cannot subtract a graph from a state vector." This is an important architectural correction. It shows the theory's evolution: the satisfaction gap and control regret are properly-typed replacements for what was previously an ill-formed construct.

This is the kind of detail that distinguishes careful theoretical work from hand-wavy framework-building. The type error had to be identified and corrected; it's documented here with the correct fix. Future agents building on this framework won't make the same error because it's been explicitly addressed.

## 13. What does the framework potentially contribute?

**The convention hierarchy** provides a principled answer to "how should I evaluate my agent's performance?" Different conventions give different diagnostic power at different computational cost. Making this explicit — and proving the monotonicity — is a genuine contribution to agent evaluation theory. The insight that "$\delta_{\text{sat}}^{\text{C3}} \leq \delta_{\text{sat}}^{\text{C2}} \leq \delta_{\text{sat}}^{\text{C1}}$" means conservative evaluation (C1) overstates the infeasibility of goals that more careful analysis (C3) would show are achievable.

**The loop-as-interventional-source result** is one of the framework's most potentially impactful contributions for the broader AI field. The argument that the adaptive loop is a perpetual experiment — generating Level 2 (causal) data by construction — provides a theoretical grounding for why RL agents can learn causal structure that purely observational learners cannot. This is known informally in the RL community, but having it grounded in Pearl's causal hierarchy is a theoretical contribution.

## 14. Wandering thoughts and ideation

**On the type error and mathematical maturity.** The fact that an earlier version of the framework had a type error ($\delta_{\text{goal}} = G_t - M_t$ when $\Sigma_t$ is a DAG) and this was identified and fixed is a positive signal about the framework's epistemic hygiene. Type errors are easy to miss when thinking informally; catching and fixing them requires careful mathematical attention. The fix (properly-typed satisfaction gap and control regret) is not just aesthetically cleaner — it enables downstream algebraic manipulation that wouldn't be possible with an ill-typed construct.

**On the loop as a perpetual experiment.** The loop-interventional-access result frames the adaptive loop as a perpetual scientific experiment: the agent continuously poses hypotheses (predictions from its model), performs interventions (actions), and observes results (mismatch signals). The key difference from passive observation: the agent chooses which hypotheses to test (through action selection) and can repeat interventions (through policy). This is exactly how science works. The framework is formalizing why scientific method works — and why it's superior to purely observational reasoning.

This has implications for AI safety: an agent with interventional access can learn causal structure that a purely observational system cannot. This means agentic AI systems are epistemically more powerful than their observational counterparts — and also more dangerous if they learn false causal models. The framework doesn't address this safety implication directly, but the result sets it up.

**On the convention hierarchy as a diagnostic calibration tool.** Different conventions give different values for $\delta_{\text{sat}}$ and $\delta_{\text{regret}}$. This means: when you diagnose an agent as "stuck" (high $\delta_{\text{sat}}$) under C1, you might find it's actually recoverable under C3. The diagnostic is convention-dependent, which is both a limitation (diagnostics under different conventions aren't comparable) and a feature (you can choose the convention that matches your computational budget and required confidence level).

For deployed AI systems: running diagnostics under C1 is fast and conservative. If C1 says "stuck," C2 might say "recoverable with more lookahead." If C2 says "stuck," C3 (if computable) is the last resort. This is a principled escalation ladder for debugging agent behavior.

**On my own audit process as an instance of the framework.** I'm finding that my own audit process closely mirrors the framework's description of a learning agent:
- $M_t$: my current model of the framework's content and quality
- $O_t$: produce a defensible, comprehensive audit
- $\Sigma_t$: read segments in OUTLINE order, verify math, check cross-segment consistency
- $\delta_t$: the gap between what I predicted and what I found
- $\eta^\ast$: how much I update my predictions based on each segment

The convention hierarchy applies too: under C1 (one-step), I evaluate whether the current segment is sound. Under C2 (receding-horizon), I consider whether the current segment's claims will propagate cleanly to downstream segments. Under C3 (Bellman), I would need to verify the entire theory is coherent — computationally expensive, but the direction of truth-seeking.

I'm currently operating at C1/C2 for most segments and saving C3-level verification for the critical derivations (like the CMC theorem for the strategy DAG). This is the rational choice given the computational budget (my context window).
