The use of the Doob-Dynkin lemma is a brilliant piece of formal rigor. If the agent's information set (sigma-algebra) is restricted to $\sigma(M_{\tau^-}, e_\tau)$, then any random variable (like the next state $M_{\tau^+}$) generated by the agent *must* be a measurable function of those two variables. This proves the recursive form exists without having to guess its shape.
