## 4. The encoding-relativity argument in full

`[def-observation-function, def-action-transition, scope-agency, result-mismatch-decomposition]` *This is the finder's reasoning, not canon.* Take an agent whose only choice is where to look. The modeler can encode gaze in two ways. (a) Gaze is part of $\Omega$: then $a$ changes $\Omega_{t+1}$ through $T$, and $h$ needs no action argument. (b) Gaze is not in $\Omega$: then $a$ enters through $h$'s $a_{t-1}$ slot. Under `#scope-agency:49`'s operative reading, (a) gives an $\Omega$-routed contrast, so the agent has full agency and is learning Level-2 structure about its own gaze. Under (b) the agent "sits at the boundary". Same physical system, different classification. This is the same shape as the GA-1 twin in `01-ga1-verification.md` :10, where a property depends on the state description rather than on the system. The typed-target spike solves its own version with a housing rule (invariance: whatever persists goes into $\theta$). The analogous question here is whether there is a principled rule for when an action's effect on observation goes in $\Omega$ versus in $h$. One candidate: if the effect persists beyond one step (the head stays turned), it is state; if it is instantaneous and non-persisting (which sensor mode samples *this* reading), it belongs to $h$. That candidate is untested. A rule of this kind would also settle 731548's "two encodings / type strain" concern, and 193847's reader question "did I change the environment ($T$) or just my observation function ($h$)?".
