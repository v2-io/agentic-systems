**14. Wandering thoughts.** *One:* the observation-mediated boundary in both directions (unobservable $\Omega$-effects also outside agency) is philosophically heavier than the segment lets on: it makes AAT-agency an *epistemically closed* notion — you are an agent only with respect to effects your own sensorium can register. A consequence: an agent whose actions have vast unobservable consequences (a trading algorithm moving markets it never measures) is, toward those consequences, formally nominal. For the safety-facing volumes this cuts both ways — it cleanly formalizes "the agent can't learn what it can't see," but it also means AAT's agency scope systematically under-ascribes agency relative to *moral* accountability, which tracks caused-but-unobserved effects too. Volume 4's accountability factor will need a different notion than $\mathcal S_\text{agency}$ membership; if it borrows this one silently, that's a category error waiting. Worth one forward-looking sentence here or a Working Note there.

*Two:* the two-"nominal"s collision (nominal agent here, nominal coupling next door) is small but the *kind* of small that compounds: both live on the same conceptual seam (does the coupling do real causal work?), so a reader's misbinding is not random noise, it's maximally confusable. The naming-cycle should treat seam-adjacent collisions as higher-priority than distant homonyms — a principle their Criterion list may already encode; if not, this is the example that motivates it.
